# 0.4.69 / Android 196：同曲 JPW 风格校准与首尾不足拍

## 比较方法与来源

以项目根的 JPW.jpg 和用户桌面的《祈福园钟声飘过的地方.jps》作同曲比较。原JPS未改，SHA256为 AECB666B1250B61A4457DB1B29AA99AEEEB0B449ED1FFDFF464ACB1582A6639E。

`artifacts/jpw-layout-analysis/actual-original.jps`保留原样；`actual-no-padding.jps`只移除首尾各一颗明确补拍的四分休止符，不移动歌词；`祈福园-JPW风格对照.jps`再显式设置字号24、字距-14。以原图数字实际墨高H=21px归一输出，按原图版心比例设置左右留白。归一图为8行；物理缩放与DPI不是字号风格的判断依据。

## 字体结论修正

0.4.68曾使用Noto Serif数字和宋体类歌词；逐字形比较表明这两项并非最接近参考。参考数字更接近粗黑体与窄1。新离线数字由OFL Arimo700与Roboto700窄1组成，统一advance和墨高。字体形态比较的Dice仅用于选择方向，不等于整页相似度：新组合平均约0.891，旧Noto Serif约0.853。参考原标题更接近宋体，歌词更接近微软雅黑常规体。

Windows优先系统宋体标题、微软雅黑歌词；其他设备使用离线Noto Serif SC标题与Noto Sans SC歌词。未复制分发商业系统字体。字体加载后实际测量“祈福那是”的平均墨高，补偿不同字库的字号，避免相同CSS字号但可见高度不同。来源、四份OFL及研究记录见public/fonts/README.md和artifacts/jpw-layout-analysis/font-research-notes.md。

## 以H为单位的校准目标

| 项目 | JPW参考量测/目标 | 实现 |
|---|---|---|
| 普通小节线总高 | 约2.05–2.14H | 2.10H，随字号缩放 |
| 普通小节线等效黑宽 | 约0.081H | 0.081H，按实际墨迹与像素量测校正中心 |
| 八度点直径 | 约0.19–0.238H | 0.23H，补偿小尺寸抗锯齿墨量 |
| 高点中心到数字墨顶 | 约0.333H | 按Canvas真实墨顶定位 |
| 减时线粗度/层间距 | 约0.070H / 0.20H | 独立保持对应比例 |
| 数字底到第一减时线净空 | 约0.24H | 按Canvas真实墨底定位 |
| 增时线长度/粗度 | 约0.667H / 0.142H | 与减时线分开，不再复用细线宽 |
| 歌词实际墨高/段距 | 约1.024H / 1.68H | 实际字体测量后统一字号、布局和输入框 |
| 标题到副标题中心 | 约3.71H | 副标题与调号同横带 |
| 调号/拍号墨高 | 约1H / 0.67–0.71H | 分角色字号，不再统一缩小 |

短弧、长平弧分别计算：普通短弧以数字墨顶为基准，单层高八度点额外抬高约0.2H；较长圆弧增加拱高，足够长的平弧使用两端圆弧和中间平段。长平弧目标中段粗度0.072H，短弧约0.098H，均保留尖细端点。有技法记号时继续避让，不为了复制截图穿过记号。

## 间距与均分

保留拍组内部较紧、组间更易伸缩；小节剩余空间权重由音符数的1.5次幂改为平方根，降低密集小节抢占余量的问题，并给增时长音额外自然空间。歌词参与最小宽度，标点附字、正文对音，不压缩字形。

纸面两端对齐改为以实际可见的末小节线中心为右锚点，行末半个占位格可探出锚点；窄屏保留格子在屏内的约束。这修复了此前看似“格宽铺满”，实际竖线还缩进半格的问题。

仅在存在显式换行的纸面谱中允许最多6%的温和收紧，同时不能小于数字/附点/歌词/标点的安全宽度。普通自动换行保留原来的自然宽度约束与可点击间隙；手机继续使用自身的安全压缩与重排范围。无法从单张成品图唯一反推出JPW所有内部均分算法，因此这里记录目标和约束，不宣称复原其源码。

## 首尾不足拍规则

根据全声部事件位置判断首、末实际小节，休止也计入。首尾不足拍不报警，无需显式弱起标记；中间不足拍仍警告，首尾超拍仍报错。换行、普通收尾线和终止线不改变判断，单小节短谱也允许不足拍。已有显式partial语义继续支持。不补拍、不改时值。独立skills/windscore-jps/validate.mjs同步重建。

## 内容差异与边界

识别JPS与图中仍有内容差别，例如第7行6563对比图中6564、第二段歌词后半段缺失、末尾pp/渐变记号未录入。这些不会由排版器猜测补写，也会影响最后几行的上下留白。源中速度60与图中的风格说明也是不同元数据。不同系统的可用字库和图片抗锯齿仍有差异，不能把该校准称为逐像素相同。
