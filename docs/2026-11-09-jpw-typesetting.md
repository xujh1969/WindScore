# 0.4.68 / Android 195：印刷简谱与歌词标点

按 JPW.jpg 的视觉方向调整共享谱面实现：Noto Serif 粗体数字、Noto Serif SC 常规中文、浅色黑墨；拍组内部较紧、组间更易吸收两端对齐余量。字距档位及显式断行继续生效，未修改音高、时值与演奏数据。

首段歌词独立定位，后续段距24个基准像素；标点附字但正文仍对准数字。中文句末标点附前字，开引号/括号附后字，闭引号/括号附前字。`你，我。`占两个音符。空格仍占原来的歌词空位；单独补标点时在对应字格中编辑。已有字符串与JPS存储格式不变，历史上已被过滤掉的标点无法自动恢复。

简谱逐行计算上、下占用；前奏不预留全曲的歌词高度，局部渐变不撑高全曲。行带支持非对称上下空间；命中区域、小节播放底色、PDF分页、PNG逐行检查同步更新。高八度+延长记号有防裁切回归。总谱维持共享时间格/统一声部行高，五线谱维持自己的墨迹避让，仅同步字体、歌词标点和正确的字体度量。

字体离线打包，来源和OFL见 public/fonts/README.md。SVG嵌入字体数据，因此文件比旧SVG大；PDF/PNG仍为位图，不依赖接收设备字体。SVG补齐绘制器setLineDash，避免普通小节线绘制时报错。后续修订（2026-11-09）：标题专用字体已移除，SVG 只嵌入数字与文本两套字体，打包与导出体积相应减小。

验证入口：`npm run test:jpw`、`npm run test:android`、`npm run build`、Gradle assembleDebug、Tauri build。`scripts/jpw-layout-preview.html` 与 `tests/jpw-layout-sample.jps` 提供可重现的桌面/390px校准节选；录入样本用于版式观察，不是完整校订曲谱。

各端：浏览器编辑/对轨/播放与Android播放器共用layout/paint，全部同步；Tauri使用同一前端资源并重新构建。首页/曲库/帮助不改业务；帮助正文补充标点规则。Android原生壳和存储后端不变，没有新增存储字段或迁移。未进行Android真机与用户原始曲库逐首验收。

基线限制：npm test在beat-test有3项BPM判定失败，使用HEAD归档复测相同；本轮未改节拍分析。导出测试夹具改为明确换行，避免数字变窄后隐含“两行”的假设失效。Android UI测试显式注入构建版本常量，与Vite编译环境一致。
