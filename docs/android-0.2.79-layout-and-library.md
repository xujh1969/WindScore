# 0.2.79 排版及曲库界面调整

## 本轮范围

- 取消曲库单独的标题、Slogan 与背景装饰区。顶部标题随当前页切换为 WindScore-曲库、WindScore-社区、WindScore-我的；曲目数量紧随“全部乐谱/收藏的乐谱”，搜索和收藏筛选后显示当前结果数量。
- 普通操作消息三秒自动关闭。删除确认、重命名输入及播放设置仍由用户操作，不用定时器打断。
- 原生复制按钮直接复制当前有效服务地址，成功提示“地址已复制，请在同一局域网的电脑浏览器中打开此地址”；失败给出手动复制提示。
- App 内切换到曲库或社区时自动停止服务并撤销地址；系统切到聊天软件发地址仍保持原会话，不混淆两种切换。
- “我的”只保留本地个人信息与两个操作入口：“从本地导入乐曲”“从网络传入乐曲”。网络入口打开带左上返回按钮的完整页面，隐藏主导航；返回“我的”保留服务状态，切曲库/社区才停用。
- 独立传曲页以电脑/Wi-Fi/手机图形、文件限制标签、三步进度、连接状态和地址卡片组织信息；启停按钮为主要操作，常驻提醒只保留亮屏、可分享地址与切页停用。浅深模式使用同一语义配色，不堆说明段落。
- Android、PC 播放/编辑设置的字距下限调整为 -20px，DSL 接受 -20px。记号占位保留安全宽度，不让负字距造成负宽度或重叠。

## 窄屏排版

根因是沿用纸面强制换行、以整小节为主要候选，以及收紧幅度上限偏保守。安卓阅读忽略纸面换行与分页，使用当前屏宽重排；普通小节优先在小节边界换行，较密集的小节额外允许完整拍组边界参与全局断行，减少孤立单小节行。自动间距分配遵守字形、变音记号、倚音、歌词与长音线的最小占位，保留当前字号，不通过缩小字体塞入固定小节数。短尾行仍保留合理自然宽度，避免少量音符被夸张拉宽。

手机默认分谱使用此逻辑。平板总谱仍按对齐小节系统排版，不随意拆开不同声部的节拍网格；可以切换分谱使用拍组断行。PC/导出保留谱中指定的换行。

## 跨端和交付

原生剪贴板、切页停用、曲库顶部布局及提示计时只影响安卓入口。字距范围、符号安全宽度及间距求解器是共享代码，因此同时构建 0.2.79 Windows exe；非安卓断行仍使用原来的压缩代价与原谱换行。

本轮只递增一次版本至 0.2.79 / Android 构建 6；安装包统一交付 `artifacts/releases/`。浏览器手机预览检查与原生构建不能代替真机剪贴板、服务关闭和实际曲谱的验收。
