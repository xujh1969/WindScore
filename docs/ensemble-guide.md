# 重奏制谱与简洁 JPS 使用说明

本轮交付：独立声部、总谱/分谱、同步试听、总谱/分谱 PDF 与视频输出，以及编辑器默认使用的 JPS 3 简洁语法。旧文件先按原规则读取，再转换为新版表示。

## 界面操作

1. 在编辑器的「声部」栏点击「新增声部」。新声部按首声部已有小节生成休止符，随后逐小节填写旋律。
2. 点击声部标签，或直接点击总谱中的音符，切换编辑对象。拖拽一个标签到另一个标签上可互换位置；只有选中的标签显示配置和删除图标。配置弹窗设置名称、音量、独奏与静音，点击「保存设置」生效；删除前确认声部名称，至少保留一个声部。这些改动支持撤销。
3. 「总谱」同时显示所有声部；「当前分谱」显示当前声部。谱面上的名称、左侧连谱号和共同小节线帮助辨认重奏结构。同一时间的音符纵向对齐，换行以完整小节为单位。
4. 配置弹窗中的「静音」「独奏」「音量」控制各声部的合成试听。各声部共享起播时刻、速度和播放进度，谱面同时显示正在演奏的音符。播放中可打开配置弹窗调整试听设置，保存后生效。
5. 导出窗口可选择总谱或任一分谱。PDF 分页保留整组声部；视频沿整组谱行滚动并显示各声部播放位置。分谱文件名附带声部名称。

示例下拉框提供「欢乐颂（二重奏示例）」和「小星星（四声部示例）」。四声部示例包含主旋律、和声、分解和弦与低音，共十二小节。现有单声部谱可通过「新增声部」转为重奏。编辑器默认使用新版简洁语法，无需点击启用按钮。

总谱中长音和长休止的每条增时线都占据对应拍位，与其他声部的音符纵向对齐，例如 `1---` 的三条线分别位于第二、第三、第四拍。点击任一增时线会选中所属音符。当前分谱仍使用单声部的紧凑增时线排版。

## 全谱结构规则

- 每个声部独立记录旋律和时值，共享谱头调号、拍号和速度。
- 各声部的小节数量与对应小节时值应相同。校验区会提示不一致，修正前禁止同步试听；不会猜测或拉伸音符时值。
- **首声部统一定义反复、跳房子、D.C./D.S. 等跳转、弱起、拍号变化和手动换行/分页**，其他声部按对应小节继承。请在首声部编辑这些结构。
- 同一声部仍是一条旋律线。需要同时演奏的独立旋律请建立不同声部；同一声部内的局部复调属于后续功能。
- PDF 保留当前谱面的每行内容、字号和间距比例，整行等比适配纸张，窗口提供逐页预览。某一整组声部无法装入页面高度时会提示，可在谱面中减小字号、增加每行小节数，或导出分谱。
- 静音、独奏、音量保存在 JPS 中；视频选择合成音时使用这些设置。伴奏录音仍是整首的现有音频，不会随分谱选择自动分离。
- 合成试听继续使用现有合成器，目前没有增加真实乐器音色库；范围力度目前控制谱面标记，不增加合成试听中的表情力度曲线。

## 第二阶段：拍号、范围力度与排版

编辑器示例菜单提供「拍号与力度范围（重奏示例）」。

- 点选首声部的小节线，在右侧「此线之后的拍号」中切换拍号；拍数校验、自动拍组和时值档位随所在小节更新。四分音符单位的 BPM 与现有音符时值不因换拍号自动改变。
- 同一小节线的「此线之后的排版」可选自动、换行、分页。总谱中所有声部共同换行；分页同时换行，并使 PDF 从下一整组声部开始新页。屏幕和视频以换行呈现分页标记，不插入空白纸页。
- 框选至少两个音符，在右侧「跨音力度范围」选择渐强、渐弱或清除。楔形覆盖首音到末音，跨行分段延续；力度文字和楔形分层绘制，并增加行距以避让。若新范围与已有范围相交，使用新范围替换相交范围。
- 复制完整范围会同时复制起止引用；只复制部分范围时不携带残缺楔形。删除终音或把终音改成休止符会移除该范围。反复展开中的范围若跨越回跳边界而无法保持顺序，会移除并提示。

JPS 3 的对应写法：

```text
@format 3
@beat 4/4

cresc[ 1 2 3 4 | 拍3/4 换行 5 6 5 ]hairpin | 拍6/8 分页
dim[ 5/ 6/ 5/ 3/ 2/ 1/ ]hairpin ||
```

`拍3/4`、`换行`、`分页` 紧接小节线，多个标记可连续写。`cresc[` / `dim[` 与 `]hairpin` 是独立记号，需要空格分隔；范围不能嵌套。单音的旧 `cresc` / `dim` 记号仍保留。

## JPS 3 格式

新版文件在谱头写 `@format 3`，编辑器会自动添加。没有这行的旧文件先按旧语法解析，再在编辑器中自动使用新版表示；已有音高与时值保留。

```text
@format 3
@title 二重奏示例
@key 1=C
@beat 4/4
@bpm 90

@part 1 "主旋律"
@mix 1 on all
1/ 2/ 3/ 4/ 5 5 | <3: 1 2 3> 4 5- ||

@part 2 "低声部"
@mix 0.8 on all
1v- 5v- | 1v--- ||
```

`@part` 的编号为唯一正整数，名称使用双引号；声明后的内容属于该声部，直到下一条声明。声部顺序由声明顺序决定，不依赖编号大小。

`@mix` 可省略，默认音量 1、未静音、未独奏。三个参数分别是 0–1 音量、`on/off`（发声/静音）、`all/solo`（普通/独奏）。有独奏声部时，仅未静音的独奏声部发声。

| 新版写法 | 等价时值/规则 |
| --- | --- |
| `5/` | `5/2`，八分音符 |
| `5//` | `5/4`，十六分音符 |
| `5///` | `5/8`，三十二分音符 |
| `1/ 2/ 3/ 4/` | 未显式分组的普通短音自动按拍组连接 |
| `<3: 1 2 3>` | 每音 `/3`，整组共一个四分音符时值 |

原分数写法继续合法。普通拍组可使用 `< >` 明确覆盖；6/8、9/8、12/8 的自动组按三个八分音符划分。保存时省略自动组括号，读取时重新推导；显式组和连音符组保留。

省写三连音必须正好三个音、全部省略时值且没有附点或增时线。更复杂的情况请明确写每音时值，例如 `<3: 1/3 2/3 3/3>`。旧语法中的 `<3: 1 2 3>` 不会被静默改成新版含义。

## 歌词与图片输出

编辑页点击「新增声部」，选择「歌词」类型、行名与关联演奏声部，每声部最多六条歌词行。点击声部栏带「词」的标签，直接在谱面歌词格输入；一次输入中文词句会逐字分配到连续主音并自动前进，输入法组合期间不跳音。新输入单字后空格确认，空白格按空格跳过该音；回到已有字的格子按空格，在该字前插入空位并顺延后续歌词。词句输入也保留并顺延后续文字；容量不足时提示，不截断尾部。上述操作可撤销。Tab/Enter/右方向键前进，Shift+Tab/左方向键后退；休止、倚音和小节线自动跳过。前奏间奏可直接点击对应音符或歌词格定位。离开输入格写入单字，「结束歌词输入」或 Esc 返回写谱。

选中的歌词标签显示配置与删除按钮，行名和关联声部可以调整，删除需确认并可撤销。更换关联声部按主音顺序对应；目标音符不足或歌词行已满时保留原内容并提示。歌词名称用关联声部声明后的 `@lyricNames ["第一段", "第二段"]` 保存；旧文件自动推导行名，空歌词行也会保留。文字继续附着于音符，随复制、删除和反复展开处理；演奏声部互换位置时关联歌词随行。歌词基础字号为 16、段间距为 24，随谱面缩放；旧文件或源码的一音多字仍保留，长词组会在本音格宽内压缩，可增大字间距改善显示。

JPS 3 可在声部主体后写：

```text
1 2 3 4 ||
歌词1: 春 风 _ "hello world"
歌词2: 星 光 照 路
```

「导出 PDF」打开的弹窗增加「图片」选项，可输出 PNG 长图或 SVG 矢量图片，并选择总谱/分谱、宽度、深浅色、标题和小节号。谱面、PDF、视频、图片共用歌词绘制。长图保留强制换行，分页不增加纸页空白；过长 PNG 会提示改用 SVG/PDF。SVG 文字使用打开设备的字体，跨设备字体不同可能改变外观。示例菜单新增「多段歌词（重奏示例）」。快捷键说明点击顶部工具栏的「帮助」查看，Esc 可关闭。
