# GB/T 46845—2025 简谱国标 · 未实现功能清单

对照国家标准 **GB/T 46845—2025《音乐曲谱出版 简谱 通用规范》**（全文：`docs/GBT+46845-2025.pdf`）逐条核对后的**待实现功能清单**，按对演奏者的实用度排序。2026-10-30 建立，对应版本 0.4.28；0.4.29 实现了高实用度全部五项与中实用度全部五项。

已实现的合规项（变音五种、噪声符 ×、跳房子斜体序号、小节号方框、校验报错附条款等）不在本清单，见 git 提交记录与 v2-test 回归块。

## 一、高实用度（演奏者日常会用到）

### 1. 小节反复号与音型反复号（§5.8.4 / §5.8.5）
- ✅ **小节反复号**（0.4.29 实现，0.4.30 完善按键语义）：𝄍 按钮只在光标紧跟小节线时有效——按一次重复上一小节（插入记号格 + 收尾小节线），再按一次重复前两小节（双斜线记号画在中间小节线上），第三次起无效。反复小节不能再写其他音符（输入拦截 + 校验报错，GB §5.8.4）。源码写法 `%`；单小节记号 = 一条左下→右上的斜线 + 左右各一点。
- **两小节反复号**：未实现（罕见，暂无需求）。
- **音型反复号**（斜线 `/`、`//`）：未实现。

### 2. 多小节休止（§6.3.7.3）
- ✅ **多小节休止**（0.4.29 实现）：DSL 写 `0*8` = 休止 8 小节；谱面画一条贯穿的粗横线、两端下钩、上方写小节数。内部按「N 个整小节休止 + 隐藏小节线」拆解，校验 / 小节号 / 换行分页全部走既有机制，序列化时合并回 `0*N`。

### 3. 8va / 8vb 八度号（§6.2.6）
- ✅ **8va / 8vb**（0.4.29 实现，DSL-only）：`8va[ 5 6 7 ]8` = 段内音高整体升八度（+12 半音），`8vb[ … ]8` 降八度。谱面在音符上方（8vb 在下方）画斜体小字 `8` + 虚线 + 末端短钩。需要 `@format 3`，不能嵌套。
- ✅ **八度重复号（con 8）**（0.4.31 实现）：`con8[ … ]8` / `con8b[ … ]8` = 原声保留、另叠一份高 / 低八度同响；谱面标斜体 `con 8` + 虚线。选区按钮循环三态：8va → con 8 → 取消。

### 4. 颤音 tr 的规范化与回音（§7.5.3 / §7.5.5）
- ✅ **tr + 波浪延展线**（0.4.29 实现）：`tr` 是技法串最后一员时右侧接固定三段波浪线（GB §7.5.3 形态）。
- ✅ **回音**（0.4.29 实现）：技法后缀 `u`（如 `1u`），谱面画横置 S 曲线（GB §7.4 字形），面板按钮随技法列表自动出现。

### 5. 指法数字（§7.11.5）
- ✅ **指法数字**（0.4.29 实现）：DSL 写 `1'2`（音符后加 `'` + 0–5，0 = 空弦），谱面画在音符正下方的小字；浮动板「技法 · 倚音 · 力度 · 记号」区有 0–5 按钮排。同音换指弧线未实现。

## 二、中实用度

### 6. 琶音（§7.7）
- ✅ **琶音记号**（0.4.29 实现）：音符右侧的波状竖线。DSL 后缀 `a`（如 `1a`），面板「气息与技法」区开关，排版预留宽度。单声部简谱里是纯记谱标记；重奏和弦的逐音延迟起音待后续。

### 7. 震音（§7.8）
- ✅ **震音**（0.4.29 实现）：音符右上 1–3 条斜线。DSL 后缀 `z` / `zz` / `zzz`，面板可选；**播放时把该音均分成 2^n 份快速重复**（1 条 = 八分重复、2 条 = 十六分…），均分不净或太短就整音奏。

### 8. 虚小节线（§5.2.2）
- ✅ **虚小节线**（0.4.29 实现）：DSL `|~`（别名 `¦`），小节线面板「虚线」开关。占位、拦小节、计数、校验全部与实线一致，只是画成虚线。

### 9. 自由拍子 / 散板（§6.3.11.7 记「散」、§7.2.5 自由速度）
- ✅ **「散」记号 + 拍数校验豁免**（0.4.29 实现）：DSL「散」紧接小节线书写，小节线面板「散板」开关。此线之后拍号位置记「散」，段内小节不做拍数校验；到下一根写「拍N/M」的线自动退出。散板内音符仍按拍网格排布、播放按谱面时值——「按词组松散排布 / 自由速度」的完全体待后续。

### 10. 复拍子次强拍（§6.3.13）
- ✅ **次强拍**（0.4.29 实现）：节拍器强弱升为三档（强 / 次强 / 弱）。6/8、9/8、12/8 的第 2…N 个附点四分大拍打次强（clickSampleMedium），导出混音同步支持。

### 11. 速度文字术语与渐变速（§7.2.3 / §7.2.4）
- 慢板/中板/快板等基本速度术语；accel. / rit. 渐快渐慢记号；**播放时的渐变速曲线**（合成音 synthTempo 目前是分段恒速）。

## 三、低实用度 / 出版级

### 12. 交错拍子（§6.3.11.6）
- 不同声部不同拍号并进（软件拍号全谱统一，谱中换拍也是全局的）。

### 13. 三附点（§6.3.8.2）
- 附点最多双附点，国标有三附点（极罕见）。DSL `.000` 三连点 + ticks 系数 1.875。

### 14. 排练号 / 段落序号（§5.9.2）
- A/B/C 或罗马数字段落标记（现有跳房子的段次序号是另一回事）。

### 15. 大谱表（§5.3.2 花连谱号）
- 花连谱号（大括号）联括**一人演奏的多行谱**（古筝、钢琴简谱大谱表）；现有多声部是「多乐器重奏」，只有直连谱号。
- 附带：声部引导线（§5.6，声部移行斜线）。

### 16. 单行谱表多声部（§5.10）
- 同一行谱表内上下并列的二/三声部（增时线/减时线合记、休止符合记）；主从声部记法（旋律正常字号 + 和音小字号）。

### 17. 调号附加符号（§6.2.9.5）
- 筒音、定弦、特殊定弦等民族乐器附加标记；转调时的「前调末音=后调首音」说明。

## 四、记法宽容项（有意保留的偏差，不打算改）

- **二分/全休止的增时线写法**（§6.3.7.2）：国标规定用连写四分休止（`0 0`）而非增时线；软件允许 `0-`、`0--`，是宽松超集，实际出版物两种都有。
- **滑音/弯音形态**：电吹管形态（折线箭头/曲线），与国标箭头形 ↗/↘ 不同——对目标用户更贴切。
- **小节号频率**：国标建议每行首或每 5/10 小节标注，软件默认每小节都标（配合报错「第 N 小节」定位），每第 5 小节已画方框。
