反复线修正为双线外侧双点，起点右侧、终点左侧；普通终止线左细右粗，反复超过两遍显示总遍数并参与技法避让。重奏同步此前只处理小节边界的第一条线，遗漏同拍另一条反复起点；现按首声部重建额外结构线，避免多次同步累加。样张见 `artifacts/staff-auto-clef/`；完整展开演奏及导出仍待实际验收。

用户反馈自动选低音过于激进后，谱号策略已修正：`resolveStaffClef` 仅执行明确的 `bass`，其余（含旧 `auto`）均为高音。分析移到独立 `suggestStaffClef`，持续低音至少占 80% 时长权重、高音加线负担明显且低音代价低于一半才建议；UI 提供应用按钮，应用后保存 `bass`。不改动已手动指定的谱号。此前自动选择的历史实施描述由本条修正覆盖。

最新截图反馈后进一步区分“低音建议”和“明确低音”：普通声部高音优先，一般低音仍只建议；只有达到建议门槛、同时至少 80% 主音时长权重需要三根以上下加线，默认／auto 才采用低音。手动指定保持。此条覆盖此前“只建议、不自动切换”的过度保守策略。

低音谱号保留标准 U+1D122 字形，以实际 ascent／descent 将墨迹定位在谱表中部，不再直接用字体 middle 基线对齐第四线。Segno 谱面缩小约两成，按钮同步缩小。谱线取消末端额外留白，收在小节线坐标；两端补充与谱线同边界的竖线，使用 butt 收口避免外伸。曲线与导出继续使用相同几何。

## 1. 目标与范围

同一份曲谱支持简谱、实音五线谱、乐器移调五线谱。切换视图后，音乐含义、实际发声音高、时值、伴奏对齐与事件身份保持一致。

本阶段完成：

- 完整呈现已有音符、装饰音、演奏记号、歌词与反复结构。
- 每声部独立设置乐器移调关系与谱号，总谱支持实音／移调显示。
- 使用相同的五线谱布局支持显示、命中定位、打印和动态视频。
- 保持旧 JPS、曲库和 WSPACK 的兼容性。

暂不扩展为通用打谱系统：五线谱直接输入编辑、任意微分音和复杂嵌套连音组另行排期。无法精确表达的内容必须明确保留或提示，不能静默丢失。

## 2. 当前实现与限制

| 模块 | 当前职责／限制 |
| --- | --- |
| `types.ts` | 已保存延音线、圆滑线、倚音、装饰音、力度、技法、自定义标记和歌词等音乐含义 |
| `staff.ts` | 从简谱排版投影位置，计算谱表音高、符干和符杠；尚未形成完整的五线谱语义与独立排版 |
| `staffPaint.ts` | 绘制谱线、谱号、调号、拍号、基础音符、符杠、歌词和部分反复内容；存在代码不等于已完成验收 |
| `timeline.ts` | `toMidi()` 按旧简谱调号／八度约定计算声音；主音取靠近 C4 的八度，不是乐器移调模型 |
| `ScoreCanvas.tsx` | 切换绘制路径；五线谱需要自己的符号包围盒与命中坐标 |
| 导出模块 | 需要正式接入五线谱布局，不能只切换屏幕上的绘制函数 |

具体问题：

1. `normalizeOctave()` 按旋律中位音自动移动显示八度。严格实音谱不能由此隐式改变位置；其返回值当前是自然音级格数，也不是可直接保存的八度数量。
2. `keySignature()` 当前按音高类别选择升降号较少的一侧，不能完整保留 F♯／G♭ 等原有调性拼写。
3. `staffPosOf()` 缺少完整的小节临时记号状态，不能逐音孤立判断升降号。
4. 符干方向、符杠和加线应在最终书写音高确定之后计算，不能先定方向再整体挪八度。
5. 直接沿用简谱横坐标，无法可靠容纳五线谱的变音记号、倚音、符尾和跨音记号。

## 3. 核心原则：音乐含义与谱面坐标分开

保留 `Score` 为唯一可编辑真源，不另外保存一份独立的五线谱音符列表。

```text
JPS / Score（含原始记号和稳定事件 ID）
  ├─ 音高解析 → 实际音高与音名拼写 → 播放声音
  ├─ 记谱方式 + 声部乐器 → 书写音高／调号 → 五线谱布局 → 绘制
  └─ 反复展开 + 时间线 + TempoMap → 播放定位／视频帧定位
```

- 从 `Score.events` 读取记号；声音时间线可能合并延音，不能用它重建完整记谱。
- 音高移动、显示八度移动与反复展开，都必须保留事件 ID／`originId` 的对应关系。
- 记号通过音符 ID、起止音或小节边界绑定，不能绑定屏幕像素。
- 第一版可继续使用现有 Canvas 绘制；先建立正确的含义与布局，不为本阶段更换整套技术栈。

## 4. 现有记号的转换规则

| 简谱数据／记号 | 五线谱表达 | 实现要点 |
| --- | --- | --- |
| 音级、八度、变音 | 音名、八度、符头位置、临时记号 | 保留音名拼写，支持还原号，避免只从 MIDI 猜音名 |
| 时值、增减时线、附点 | 音符类型、符尾／符杠、附点 | 按基础时值推导外形，区分附点、连音组后的实际 tick；不能只比较总时值阈值 |
| 延音线 `tie` | 同音高符头间的延音弧 | 校验实际音高；跨行拆段；声音持续，显示按内部节奏前进 |
| 圆滑线 `slur` | 乐句弧线 | 多音链归并；按符干、连音数字和技法避让；不将其一律当成延音合并 |
| 前／后倚音 | 小音符、必要的符杠和连接弧 | 保留顺序和附着主音；不增加小节总拍数；斜杠样式需有明确含义，不能由前后位置猜测 |
| 三连音等 `tuplet` | 数字与必要括线 | 实际 tick 与书写时值分开；符杠分组受拍号和连音组共同约束 |
| 跳音、保持音、强音等 | 标准奏法符号 | 靠近对应符头，按符干方向与空间决定上下位置 |
| 延长号 | 标准延长号 | 优先放在音符／休止符上方，检查与弧线的重叠 |
| 颤音、上下波音、回音 | 对应装饰音符号 | 含义明确才映射；装饰音的临时升降号需要独立空间 |
| 换气 | 标准换气记号 | 绑定音尾或拍间位置；与小节线、倚音分开占位 |
| T／K 吐音 | 文字式吐音指示 | 保留原字母序列，不从 T／K 序列擅自推断另一种演奏法 |
| 花舌、打音、滑音、弯音 | 标准技法或文字说明 | 先建立逐项含义表；不明确的技法保留原文字，不凭外形替换 |
| 自定义 `mark`、段落文字、左右括号 | 原文字／括号 | 保留原文与范围，布局时避让；不擅自改写成标准技法 |
| 力度 `dynamic` | `pp` 至 `ff` 等标准力度字形 | 通常在谱表下方；总谱、歌词和多声部须另行避让 |
| 渐强／渐弱及 `hairpinTo` | 有起止范围的楔形 | 按音符 ID 定界；跨行续接；缺少终点时保留旧谱短记号语义 |
| 多段歌词 | 字位、分段、延唱线 | 不把所有空歌词都当延唱，前奏／间奏空位与延唱需要区分 |
| 反复、跳房子、D.S.／D.C.／Coda／Fine | 标准结构记号 | 原谱呈现结构；展开谱按现有规则处理，不重复生成结构标记 |
| 转调、变拍号、速度与段落指令 | 新调号、拍号、速度和说明文字 | 边界生效，行首续写；移调后同步转换调号 |
| 隐藏休止／小节线、灰显 | 保留占时／结构或灰色显示 | 不改变时值、编号与播放；隐藏对象不能在五线谱重新出现 |

无标准对应的技法先使用可读文字。后续若引入统一音乐字体，应核对字形覆盖、许可证与桌面离线打包；不能依赖用户电脑恰好安装某种字体。

## 5. 音高与移调模型

### 5.1 三个不同概念

1. **源谱音高解释**：旧简谱中的音级、调号和八度究竟代表什么声音。
2. **乐器移调**：乐器书写音高与实际发声音高的固定音程关系。
3. **显示八度／谱号**：选择高音、低音谱号或明确的八度记号，方便阅读。

这三个概念必须分开。更换谱号不改变音高；切换实音／移调显示不改变声音；真正“整首升调”是修改音乐内容的独立编辑操作。

### 5.2 音高表示

建议在投影计算层使用以下含义，不要求立即改写所有旧事件：

```ts
interface SpelledPitch {
  step: 'C' | 'D' | 'E' | 'F' | 'G' | 'A' | 'B';
  alter: number; // -1 降，0 自然，1 升；后续可扩展重升重降
  octave: number; // C4 = 中央 C
}

interface InstrumentTranspose {
  diatonic: number;   // 书写 → 实音的自然音级位移；含八度
  chromatic: number; // 书写 → 实音的总半音位移；含八度
}
```

派生 MIDI 供播放；谱面使用音名、变音与八度。两个移调量均含完整八度，不能再重复叠加一个八度字段。

公式：`实音 = 书写音 + 书写到实音的乐器移调量`。实音转换为乐器谱时，使用逆变换。

| 乐器配置 | 自然音级位移 | 半音位移 | 同一实音 C4 的书写音 |
| --- | ---: | ---: | --- |
| C 调、无八度移调 | 0 | 0 | C4 |
| B♭ 单簧管 | -1 | -2 | D4 |
| B♭ 次中音萨克斯 | -8 | -14 | D5 |
| E♭ 中音萨克斯 | -5 | -9 | A4 |

不能仅提供“B♭／E♭”选项而省略乐器音区：同为 B♭，单簧管与次中音萨克斯相差一个八度。

### 5.3 源谱、声部与设置持久化

- 旧谱缺少新字段时，按现有 `toMidi()` 解释为既有实际音高，保持声音不变。
- 将来允许输入乐器记谱音高时，需要明确的“源谱音高模式”和源乐器信息；默认仍是旧谱规则。
- 路径必须是“源谱 → 实音 → 目标书写音”。源谱已是乐器谱时不能再次直接加同一个乐器偏移。
- 在 `PartInfo` 及单声部兼容入口保存乐器标识、谱号等必要信息；实音／移调查看选择作为视图状态保存。
- JPS 新语法先确认格式与版本策略，再同步解析、序列化、复制、撤销、曲库、WSPACK 和文档；此文档不宣称已有可用的新指令。
- 音色 program 与记谱乐器独立，选择萨克斯音色不自动触发移调。

### 5.4 调号与临时记号

1. 保留源谱调号的音名拼写，不默认把 F♯ 大调换成 G♭ 大调。
2. 转换目标乐器音程时，同时转换主音字母与半音，生成一致的书写调号。
3. 每个声部／谱表维护临时记号状态，按“音名字母 + 八度”记录；小节开始恢复调号默认状态。
4. 无记号时看小节状态；显式还原号具有取消变音的含义。须先核对旧 DSL 的实际语义，不能直接改全局 `accidentalOffset()` 导致旧谱声音变化。
5. 同小节同音复现、跨小节延音、转调及行首续写分别处理；跨小节延音的记号不能按新起音随意重画。
6. 所需重升／重降超出现有格式支持时，明确报告限制或允许显式选择等音改写，不能静默改调。

### 5.5 八度显示

- 严格实音视图默认取消按旋律中位音自动移八度；允许用户改用低音谱号或明确选择八度显示方式。
- 乐器规定的八度移调属于乐器模型，不能与阅读辅助重复计算。
- 如提供 8va／8vb 显示，明确记录其作用范围和方向，并与书写音高共同解释实际发声；不能仅移动符头再随意贴标签。
- 旧谱可暂保留“兼容显示”入口，但须标明其行为；不要将旧视图表现冒充严格实音谱。

## 6. 排版、避让与交互

按最终书写音高执行以下步骤：

1. 计算谱号、调号、拍号、音符、倚音和变音记号的最小宽度。
2. 按小节、节拍与声部共享时间格分配横坐标，再按可用宽度断行。
3. 计算符干方向、符杠斜率、符尾与加线；端点复用同一套几何数据。
4. 放置延音线、圆滑线、连音数字与奏法；起止点按符头／符干包围盒定位。
5. 放置力度、楔形、歌词与说明文字；按实际占用扩展行高及声部间距。
6. 跨行生成弧线／楔形／歌词延长线的续段，保留原始引用关系。

先实现确定性的包围盒与分层避让，不引入复杂的通用物理求解器。必要时增加空间，避免为挤进固定行高而让记号重叠。

五线谱提供自己的命中索引，包含符头、倚音、弧线与记号；播放头和光球跟随最终坐标，点击起播仍通过事件 ID 找时间位置。不能继续使用简谱数字的旧点击区域。

## 7. 显示、导出与性能

- 屏幕和 PDF／PNG／SVG／视频使用同一种五线谱布局结果与几何含义；允许各输出独立选择纸张、画幅和行宽。
- PDF 按完整谱表系统分页，避免把重奏声部拆开；SVG 需实现五线谱矢量输出，不能假设 Canvas 接入后自动支持。
- 视频仍按既有 `TempoMap` 将帧时间换算为 tick；移调或换记谱法不得改变音频裁切、采样率处理或编码时间戳。
- 声音时间线可以合并延音；显示时间线保留各音节奏位置，光标、高亮条和光球继续逐音前进。
- 按曲谱版本、声部配置、记谱方式和版面参数缓存音高投影／排版；视频导出开始时计算一次，逐帧只更新定位和绘制。
- 不承诺新增符号绘制开销为零；实现后在相同曲目、尺寸、帧率与设备上比较导出耗时和音画对应关系。

## 8. 分阶段实施与验收

| 阶段 | 开发内容 | 完成标准 |
| --- | --- | --- |
| P0 音高基础 | 旧谱基准八度、音名拼写、调号、实音／移调转换、谱号 | C4 在各乐器下按上表显示；来回切换音高无累计偏移，旧谱声音不变 |
| P1 基础记谱 | 临时记号状态、时值外形、加线、符尾／符杠、附点、连音组 | 高升降、还原、不同八度、混合时值和变拍号均能正确表达 |
| P2 音符关联记号 | 延音／圆滑线、倚音、奏法、装饰音、文字技法 | 标记不丢失、连线不接错、跨行可续接，重奏各声部不串线 |
| P3 范围与结构 | 力度、渐变楔形、歌词延唱、反复与跳转 | 起止音一致，空歌词与延唱区分，原谱与展开谱均正确 |
| P4 输出与交互 | 命中、播放头、光球、各类导出及性能 | 屏幕与导出含义一致，点击定位正确，音画同步保持 |
| P5 收尾 | 示例谱、帮助文档、旧格式往返兼容、发布 | 功能覆盖清单全部有结果，再决定是否取消实验标记 |

建议准备的验收材料（实施阶段执行，本次文档任务未执行这些检查）：

- C／G／F／F♯／G♭ 等调号，跨小节转调、同音还原、延音跨小节。
- B♭ 单簧管、B♭ 次中音萨克斯、E♭ 中音萨克斯与 C 调声部的同音重奏。
- 高低音区、双附点、三连音、混合符杠、单独短音、休止与隐藏对象。
- 跨行弧线、复倚音、密集技法、力度与两段歌词共存。
- 同一曲目原谱／展开谱、实音／移调、屏幕／PDF／图片／视频对照。
- 同一批旧 JPS 的解析序列化与播放前后对照；既有节拍测试问题单独记录，不归因于五线谱。

## 9. 模块落点

- `types.ts`、`dsl.ts`、`parts.ts`：最小必要的持久化字段与兼容规则。
- 建议增加小型纯函数音高模块，供 `timeline.ts` 与 `staff.ts` 共用；不把移调逻辑散落在界面按钮中。
- `staff.ts`：书写音高、独立五线谱几何、记号锚点、命中索引。
- `staffPaint.ts`：消费布局结果绘制，不重新推导调性与移调关系。
- `EditorApp.tsx`、`ScoreCanvas.tsx`、声部配置界面：记谱方式切换、乐器配置和定位。
- `expand.ts`、复制／删除／重排逻辑：维护弧线、楔形等跨事件引用。
- `export/`：五线谱输出与布局缓存；声音和时间换算继续使用既有实现。

## 10. 待明确的产品选择

本节早期 P0 选择现已部分落实，当前待办以 [路线图](roadmap.md) 为准：

1. 已确定：保留已有简谱的实际发声解释，从同一数据生成实音谱／乐器移调谱；旧谱音高语义迁移和直接五线谱输入另行设计。
2. 已实现：C 调、B♭ 单簧管、B♭ 次中音萨克斯、E♭ 中音萨克斯；更多乐器按实际需求扩充。软件记谱配置不控制硬件移调。
3. 已实现主要技法映射，波音／弯音沿用用户确定的路径；特殊技法继续保留约定字形或文字，新增标准符号按需求确认。
4. 已确定：不自动挪八度；各声部可选高音／低音谱号。默认高音谱号，极端音区与谱号定位仍需覆盖检查。
5. 已确定：导出严格跟随乐谱界面的谱式、音高模式、声部乐器和谱号，不在导出窗口提供另一套配置。

## 11. 规范参考

参考其音乐含义和模型，不要求本阶段实现 MusicXML 导入导出：

- [MusicXML：transpose](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/transpose/)：书写音高到实际音高的音程关系。
- [MusicXML：实音总谱](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/concert-score/)：实音模式与八度移调的区分。
- [MusicXML：音高与移调教程](https://www.w3.org/2021/06/musicxml40/tutorial/midi-compatible-part/)：音名、变音和八度，以及移调量的表达。
- [MusicXML：note](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/note/)：声音含义与记谱含义分离。
