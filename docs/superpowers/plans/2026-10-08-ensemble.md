# 重奏与 JPS 简化实施计划

**Goal:** 在保留旧谱的基础上交付完整重奏编辑、排版、播放与输出，以及新版 JPS 简写。

**Architecture:** 第一声部复用现有事件流，其余声部独立存储。编辑器使用声部投影，整谱保存；排版、时间线和反复展开支持整谱。

**Tech Stack:** TypeScript、React、Canvas、Web Audio、现有 PDF/视频导出。

## 约束

- 不运行测试套件；使用编译、构建和代码检查。
- 不提交、不覆盖既有未提交工作。
- 所有建议语法在新版中显式启用，旧谱语义保持。
- 本轮按已经批准的规格在当前会话执行。

## 实施顺序

- [x] 1. types.ts 与新增 parts.ts：声部数据、投影、替换、ID 重映射、小节比较和演奏顺序共享。
- [x] 2. dsl.ts 与 edit.ts/validate.ts：版本、声部读写、时值短写、三连音省写、复合拍分组、声部 ID 分配。
- [x] 3. layout.ts 与 ensembleLayout.ts：共同时间坐标、系统换行、声部命中；paint.ts 绘制名称/连谱号/多个播放头。
- [x] 4. timeline.ts、expand.ts、audio.ts：独立声部同时播放、统一展开、最长声部结束、各声部音量。
- [x] 5. EditorApp.tsx、ScoreCanvas.tsx 与 PartsPanel.tsx：声部管理、总谱/分谱编辑、完整保存与撤销、试听控制。
- [x] 6. export/render.ts、ExportDialog.tsx：系统分页、总谱/分谱导出、视频播放指示。
- [x] 7. 更新 JPS 使用参考、研究文档和开发地图；编译与构建，处理诊断。
