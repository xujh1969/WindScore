# 重奏增时线拍位对齐与四声部示例

## 需求与原因

总谱音符已经共享各声部的时间网格，但增时线仍按固定字距绘制，导致长音后续拍位与其他声部不一致。

## 改动

- 重奏网格加入每条增时线的时间位置，给布局项提供绝对横坐标；绘制器使用这些坐标。
- 长音点击范围延伸到末条增时线，点击后续增时线仍选中所属音符。
- 单声部、当前分谱保持原有紧凑排版。
- 新增十二小节《小星星》四声部示例，加入编辑器示例乐谱菜单；包括旋律、和声、分解和弦与低音。
- 使用说明与帮助中心同步记录操作与对齐规则。

## 观察与构建

- TypeScript 检查和 Vite 生产构建通过。
- 编辑器载入四声部示例，谱面校验通过；人工查看四个声部及低音增时线的对齐。
- 点击首小节低音末条增时线，选中第一小节倍低音 1，显示时值四拍。
- 截图：`docs/screenshots/quartet-beat-alignment.png`。
- 查看后恢复原有编辑草稿；未运行自动化测试，未单独验收 PDF、视频或音频试听。
