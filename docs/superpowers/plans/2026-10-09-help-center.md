# 分类帮助中心

用户要求：总结整个软件的功能使用方法，按类别组织帮助，集成到各页面帮助入口。

## 方案与范围

- `docs/user-guide.md` 为唯一手册正文，涵盖十二类：快速开始、记谱编辑、快捷键、小节与演奏结构、重奏制谱、歌词、伴奏对轨、曲库与存储、动态谱演奏、导出与分享、JPS 源码、常见问题。
- 独立 `help.html` 从首页进入；应用内通过原生模态对话框阅读同一手册，保留编辑/播放上下文，默认定位当前页面相关分类。
- 左侧分类与全文关键词搜索，右侧正文与前后章节；窄屏目录横向排列。沿用浅色/深色与金色主题，不新增运行依赖。
- 手册只使用标题、段落、表格、列表、行内代码、粗体与代码块，由安全的 React 文本渲染子集展示，不执行 HTML。
- 页面覆盖：首页、记谱、源码、对轨、曲库、演奏首页、曲目播放；保留隐藏实验页的帮助入口，但不恢复首页实验入口。

## 执行与检查

1. 对照现有 UI 和内核写手册，纠正旧说明的过时内容。
2. 加入共用 HelpCenter / HelpDialog，配置独立页面与页面入口。
3. 编译和生产构建，人工查看分类、搜索、主题、关闭与当前页面状态；不新增或运行自动化测试套件。
4. 更新 README 和项目地图，保存帮助中心截图。
