# 歌词退格与谱面键盘焦点

- 歌词退格删除选中的字；空白格或光标在字前时删除前一歌词位置，包括空位。后续文字前移，末尾留空，连续退格在首格停止。
- 行修改通过既有编辑提交，可撤销。同步完成文字写回后再设置输入光标，避免快速连续退格删掉前移后的下一个字。输入法组合期间仍使用原生退格。
- 复现新增音符失败：音符间距滑杆获得焦点后点击谱面，焦点仍留在 INPUT，数字键被编辑器的输入保护忽略。画布增加可聚焦性，并在普通谱面点击时取得焦点；歌词格与标题配置仍走各自交互。
- 示例中的 3/4、6/8、4/4 是小节后的变拍号；点击数字现在可选中所属小节线，沿用现有拍号设置。

浏览器已观察修复前后滑杆/谱面焦点、新增音符的计数变化（16 → 17）、变拍号设置、歌词删除后前移、连续退格以及撤销恢复。临时编辑完成后恢复原会话。未新增或运行自动化测试，真实输入法候选窗口未验收。
