# 歌词词句输入与字号

## 需求与实现

- 中文词句在输入法完成组合后逐字写入连续主音；粘贴也走同一逻辑。保持休止、倚音、小节线不占歌词位置。
- 多出的字插入后续位置，后续已有歌词顺延。回到已有字按空格在它前面补空位；新输入单字空格确认，空白格空格前进。
- 若顺延将丢失末尾文字，整次操作不写入并提示。单次分格或插空位是一次编辑，可撤销恢复。
- `lyrics.ts` 独立处理输入分词及歌词行变更；旧源码的分词语义保持兼容。
- `LyricCell.tsx` 在组合期间保留输入法按键，组合结束后等待最终 input 事件，再写入及转移焦点。
- 基础字号 12 → 16、段间距 18 → 24；`layout.ts`、`paint.ts` 和 `ScoreCanvas` 输入框采用一致尺寸。
- 用户帮助与重奏说明同步更新。

## 人工观察

在浏览器使用包含前奏、休止与倚音的八主音谱：一次填入「什么」分成「什」「么」，焦点到第三主音；回到「么」按空格得到「什／空／么」。继续输入「时候」「再回来」正确分配，末音停止且不覆盖开头。补空位与词句的撤销、重做恢复对应位置。

末尾已有「来」时插空位提示无空间，所有已有文字保留；末音输入「什么」提示位置不足且保留输入草稿。成功改写后清除错误提示。截图：`docs/screenshots/lyric-phrase-input.png`。

浏览器填入中文验证了分格结果，未操控真实桌面输入法候选窗口；输入法事件处理尚需用户用实际输入法体验。未运行自动化测试，未逐项重新导出 PDF/视频验收。

`npm run build`（含 TypeScript 检查）和 `npm run build:skill` 均通过；生产构建仍有包体积提示。
