# 歌词与图片输出实施计划

依据：用户要求收起底部帮助，并继续既定计划中的未完成能力。

1. 底部说明改为帮助按钮与弹窗，不常驻占用第二行；保留全部快捷键说明。
2. 每声部支持多段逐音歌词：音符保存歌词数组；JPS 使用独立 `歌词1:` 等行，空格分词、`_` 占位；休止符与倚音不消耗歌词位置。编辑弹窗按当前声部设置整段歌词，谱面、PDF、视频共用歌词排版。
3. PNG/SVG 输出：复用现有谱面绘制；PNG 为长图，SVG 记录路径与文字为真实矢量；共享总谱/分谱选择、标题、小节号和主题。图片保留换行，分页标记不增加纸页空白。
4. 更新示例、参考和进度记录；类型检查、生产构建，人工查看界面。不开启自动化测试套件。

本批次不包含局部复调与临时伴奏，仍需后续独立开发。
