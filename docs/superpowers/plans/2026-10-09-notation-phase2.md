# 第二阶段实施计划

依据：用户要求按已批准的功能对照排序继续开发。

1. 修复声部指针拖拽、移除提示行 → 实际拖动后检查标签顺序和谱面顺序。
2. 中途拍号 → 小节线保存后续拍号；首声部同步到其他声部；解析、自动拍组、拍数校验和时值档位使用所在小节拍号。
3. 跨音渐强/渐弱 → 起音引用终音；选区操作设置范围；复制、删除、反复展开保留有效引用；跨行分段绘制，避免力度文字重叠。
4. 手动换行/分页 → 小节线保存后续断行类型；重奏共同换行，PDF 在分页标记处开始新页，视频按谱行处理。
5. 更新参考、示例和开发地图 → 编译、构建、独立校验器重新打包；检查实际编辑界面。拖拽故障按用户请求验证；其他功能不新增或运行测试套件。

JPS 3 小节线后写 `拍3/4`、`换行`、`分页`；范围写 `cresc[ 1 2 3 ]hairpin` 或 `dim[ … ]hairpin`。旧单音力度记号保持合法，旧文件不自动迁移。拍号仅在小节边界改变；分页同时产生断行。PDF 和视频共用谱面线条几何。

暂不实施第三阶段局部复调、临时伴奏、歌词与 SVG；这些属于独立批次。
