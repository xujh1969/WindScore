# PDF 沿用可见谱面排版

## 问题

编辑视图使用容器宽度、音符间距和谱面字号/字间距；原 PDF 独立按 A4 像素宽度和导出缩放重新排版，因此强制换行前可能先发生自动换行。DPI 改变可用排版宽度，也会影响断行。

## 实现

- ScoreCanvas 上报实际 LayoutResult 和 LayoutOptions；EditorApp 保存到 ref，避免额外渲染。
- PDF 默认导出当前显示的总谱或分谱，复用实际排版；在源码视图或改选其他声部时，沿用页面的宽度及排版参数计算布局。
- planExport 以完整谱面宽度计算等比纸张适配，仅分页、不重新断行。页面边距按比例计算，避免 DPI 舍入改变分页。
- 移除导出字号设置；预览和成品共用 paintExportPage，可逐页查看，隐藏编辑标记和曲目信息设置图标。
- 此次只修改 PDF；视频和图片继续沿用各自输出规格。

## 人工观察与构建

- 12 小节示例，页面自动排为每行 4 小节；真实 150 dpi PDF 同样为 4/4/4。
- 第 4 小节设置换行、第 8 小节设置分页：预览与真实 300 dpi PDF 为 2 页，第一页 4/4、第二页 4。
- 横向纸张预览与纵向保持相同每行小节数；清晰度只改变图像分辨率。
- 实际 PDF 使用 pypdf 提取页面图像后人工查看，未运行自动化测试。
- npm run build 包含 TypeScript 检查和生产构建。

## 使用边界

屏幕像素与纸张物理单位不同，PDF 将整行等比适配纸张；保证每行内容、字号与间距比例相同。纸张方向影响物理大小和分页。重奏声部组必须整体落在一页内，过高时提示调整谱面或导出分谱。
