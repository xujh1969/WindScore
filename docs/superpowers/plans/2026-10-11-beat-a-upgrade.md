# A 路线第一轮升级

## 范围

保留浏览器离线算法，不安装模型。改进节拍证据与全曲跟踪，逐拍拍点打通波形、吸附、锚点、播放与存档；B 仅约定独立 CLI 接口。

## 实现

- 多频带对数谱流，各带归一与局部基线；局部峰阈值，修正帧时间索引。
- 周期自相关保留多个速度候选；按后续用户要求，界面自动识别不传入谱面 BPM 参考。去掉谱面长度决定倍速和负匹配仍采纳。
- 16 秒局部周期上下文、4 秒更新、全局及相邻速度约束、动态规划拍链；近似直线拟合为恒速，否则输出 beatTimes。固定 BPM 分析严格保持指定速度。
- Worker 分析全曲，可取消过期任务；鼓/伴奏/贝斯优先于人声，严重立体声相消时使用能量较强声道。
- 按后续用户要求，识别成功立即应用并同步谱面 BPM，不弹确认或速度差异提醒；已有锚点以音频绝对时刻换算，已有外部曲线保留。分析结果是音频网格，谱面原点独立匹配或手动确认。
- tempoDraft 可存 beatTimes；旧存档无该字段仍按恒速处理。AudioWaveform、锚点曲线构造、微调、打拍和倍速换算使用同一拍点时轴。

## 边界

证据分数不是准确率；速度档歧义仍可能存在。强线是按拍索引分组的编辑参照，不代表已识别小节第一拍。拍点数组范围外按端点拍距外推，前奏静音和尾奏并非已检测到真实拍点。

局部周期限制连续变化，尚不保证突变速度、无鼓音乐、极弱节奏或复拍子层级准确。复拍子的听感拍与四分音符单位仍需要用户选择速度档确认。
