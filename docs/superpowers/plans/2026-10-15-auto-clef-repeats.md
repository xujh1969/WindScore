# 自动谱号与反复线修正

用户已确认自动／高音／低音三选项，以及反复双点规范绘制方案。使用 brainstorming 技能复核已批准的规则。

1. 自动按整声部当前书写音高比较高低音谱号的加线代价，时长加权、极端值限幅；低音明显有利才切换，近似持平保留高音。手动优先，单簧管／萨克斯移调谱保留高音惯例，实音按音区。无八度改写，不逐行换谱号。
2. 设置与 JPS 增加 `auto`；未指定默认自动，已写 `treble`／`bass` 的旧谱不变。界面显示自动结果，屏幕和全部导出调用同一解析函数。
3. 反复线按粗／细线与外侧双点绘制，起始朝右、结束朝左；终止线右粗左细，合并属性不画多余第三根线。反复次数及行首边界一并处理。
4. 低音重奏、手动覆盖、移调、反复起止及次数的静态样张，生产构建；不新增或运行自动测试。同步用户指南、README、语法参考、路线图与实现记录。

加线代价属于本软件的阅读优化规则，不是通用音乐学阈值。本批不加入中音／次中音谱号、段内换谱号或八度谱号。

## 用户反馈后的规则修正

此前只比较加线代价，导致正常旋律过多切为低音。按用户要求，默认与旧 auto 均保持高音，只有显式 bass 才实际使用低音。建议分析独立：至少 80% 主音时长权重低于 C4，高音加线负担明显且低音代价低于一半才提示；提供应用按钮，用户决定。移调乐器惯例和手动高／低音保留。下方首批自动选择的实施记录仅作为历史，本条为当前规则。README、用户指南、语法参考、路线图和设计进展已同步修正；静态诊断源与样张按新策略更新。

修正后 `npm run build` 通过类型检查与生产打包，保留现有 chunk 大小提示；验证器已重新打包，未运行自动测试或验证器。诊断输出区分实际谱号与建议：默认四声部均高音，第三／第四仅建议低音；手动 bass 仍低音。按钮连续操作仍待实际使用验收。
