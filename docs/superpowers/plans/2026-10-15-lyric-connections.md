# 歌词延唱与连字

用户授权继续开发 F03。沿用歌词格，不改变旧谱文本解释。

- 空位仍为空位；增加逐格 `lyricLinks` 元数据：`extend` 表示当前空格延续前一字，`hyphen` 表示当前音节与后续文字用连字符连接。
- 编辑提供延唱、连字、取消按钮及快捷键；休止打断连接。普通输入、插空、退格及切换关联声部时，标记随歌词格移动。
- JPS 格式 3 增加独立行 `歌词线1: 2~ 3~ 5-`，数字是该声部主音序号；旧 `_`、文字 `-`、`~` 不变。无有效前字的孤立延唱不绘制。
- 简谱和五线谱用共享连接几何，跨行续接，导出与横幅使用同一数据；不改变音符、演奏时值或对轨。
- 原生绘制样张及生产构建，不新增或运行自动测试；说明、README、语法参考和路线图同步更新。

延唱标在后续空歌词格，连字标在前一音节。跨行只延续到相同声部，跨休止不连线；歌词延唱不根据音符连线或普通空位自动猜测。暂不增加英文自动音节拆分。
