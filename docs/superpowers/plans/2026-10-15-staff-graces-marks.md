# 五线谱倚音、奏法与力度续作

沿用已批准的五线谱开发方案，本轮实现优先级 1–3：

- [x] 前／后／复倚音：小符头、符干、符尾／符杠、临时记号及连接主音的弧线。按原调或乐器移调计算，保持既有倚音播放时值；既有数据不区分长短倚音，不新增输入语义。
- [x] 奏法／装饰音：断音、保持、重音、强重音、延长音、颤音、波音、弯音、滑音、吐音与文字技法。复用用户已确认的波音／弯音路径，不改变简谱字形。
- [x] 力度：音符及独立力度文字、单音渐强渐弱和范围楔形；跨行按声部续接。
- [x] 根据实际包围盒扩展行距；倚音点击定位到所属主音，光球继续按主音拍位运行。
- [x] 诊断画面检查含转调、移调、重奏与多段歌词的组合，类型检查和构建；同步路线图和帮助文档。

实施记录：`staffGrace.ts`／`staffGracePaint.ts` 生成和绘制倚音；`staffMarks.ts` 生成带包围盒的注记与楔形；`staffSpacing.ts` 根据墨迹上下边界排列谱行。前倚音和后倚音按先后顺序参与五线谱临时记号状态，但不改源谱或声音。复倚音连接弧按每颗小音符实际位置计算净空。滑音及无统一标准写法的专用技法保留文字标签。深浅主题、移调和重奏样张见 `artifacts/staff-graces/`。类型检查及生产构建通过，尚未进行浏览器中连续操作和完整导出验收。

不在本轮实现跳转结构、歌词延唱、新的五线谱输入模型或五线谱导出。不运行未被请求的自动化测试。
