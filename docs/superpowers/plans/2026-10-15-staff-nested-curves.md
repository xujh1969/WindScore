# 五线谱嵌套连线避让

用户授权由开发方决定下一项。继续 F04 的嵌套连线，随后再处理需要新歌词语义的 F03。沿用 brainstorming 技能核对已有设计方向，不增加配置或输入格式。

1. 保留同一音符的多个向后圆滑线连接；仅合并没有分叉或汇合的连续链。按短跨度到长跨度生成，等跨度延音在圆滑线之前。
2. 外层曲线避开同方向、同一声部行内已生成的内层曲线。保留符头附近端点，间距在共用端点处逐渐收拢；跨行保持方向。用现有二次弧形的解析极值求所需弧高，不采用固定叠加高度。
3. 深浅主题样张涵盖内外嵌套、共用端点、分叉、跨行及延音／圆滑线组合；生产构建。按约定不新增或运行自动测试。
4. 更新 README、用户指南、路线图及实现说明，记录实际覆盖边界。

验收目标：源谱连接不丢失；嵌套曲线同向时分层，端点仍在符头附近；下游技法、行距和所有导出复用调整后几何。不改变演奏时间或声音。交叉而非包含的任意曲线及倚音小弧线之间的全局优化不属于本批。
