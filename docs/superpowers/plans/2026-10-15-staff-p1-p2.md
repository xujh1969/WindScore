本轮范围：沿用旧谱实际音高与节奏，补齐 P1 基础外形及 P2 延音／圆滑线。保持现有简谱、波音和弯音设置。

- [x] 附点音符按原始时值选择符头、符干与休止外形；独立符尾及多层符杠／短钩。
- [x] 连音组数字与括号、变拍号续行、隐藏休止、合法延音的临时记号。
- [x] 按声部分别生成延音／圆滑线，合并圆滑线链，支持跨行续段。
- [x] 按谱表、加线、符干、连线与歌词的实际占用扩展行距，跟随滚动同步新坐标。
- [x] 生成诊断画面检查上述组合，类型检查与生产构建；更新路线图及用户指南。

验证记录：`npm run typecheck`、`npm run build` 通过；原有构建包体积警告仍在。诊断样张见 `artifacts/staff-p1/`，覆盖独立短音、混合符杠、三连音、极端音区、跨行延音／圆滑线、临时记号、重奏变拍号和《青花瓷》，检查了深浅主题。代码审查发现并修正了组内高音反向符干、整／二分休止位置，以及弧线控制点不等于实际曲线净空的问题。尚未进行浏览器内连续播放或导出验收。

本轮不改旧 DSL 还原号的实际发声，不将完整技法／倚音／力度／导出标为完成；这些沿用后续阶段计划。未请求运行自动化测试。

后续修正：端点自身不作为圆滑线避让障碍；以弦线为基准分配两个控制点，初始弧高为跨度的 12%，再按实际曲线位置避让中间音符，比较上下两侧代价并保持跨行方向。修复《青花瓷》短连线被端点符干撑成 U 形的问题，浅／深色预览见 `artifacts/staff-curves-light.png`、`artifacts/staff-curves-dark.png`。播放底色移到音符绘制之前，使用带边框的圆角底色，取消覆盖符头的色块及竖线；音符墨色保持不变。

再次修正：移除连接端点到符干末端的策略，端点均固定在符头附近。五线谱播放按所选效果分别处理：光球模式复用 `ball.ts` 的时间轨迹及共享光球绘制，重排时缓存最终符头落点；非光球模式保留底色高亮。浅／深色光球样张见 `artifacts/staff-notehead-ball-*.png`；生产构建通过。
