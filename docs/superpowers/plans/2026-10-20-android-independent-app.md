# 安卓独立应用界面实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**目标：** 为 WindScore 安卓端提供独立、精致、适配手机和平板的曲库、社区、个人页和动态谱播放器，并提供可在普通浏览器中交互预览的入口。

**方案：** 新增 `android.html` 与独立的 `AndroidApp` 外壳，继续复用现有曲库、`.wspack`、谱面解析、画布和音频播放器。安卓壳改为打开新入口；浏览器通过 `android.html?preview=1` 进入带隔离示例曲目的预览模式。安卓外壳负责主导航、主题、导入和页面级响应布局；现有播放器增加安卓专用呈现入口，避免复制播放内核。

**技术栈：** React 18、TypeScript、Vite、现有 `libraryStore` / `alignStore` / `packBundle` / `ScoreCanvas`。拼音检索使用 `pinyin-pro` 的浏览器 ESM API；新增依赖前按官方安装文档锁定依赖并更新锁文件。

## 文件结构与职责

- 新建 `android.html`：安卓 Web 入口，声明 `data-entry="android"` 并挂载根节点。
- 修改 `vite.config.ts`：将安卓 HTML 加入 Vite 多页输入，安卓构建继续使用相对资源路径。
- 修改 `src/main.tsx`：根据入口加载独立安卓应用。
- 新建 `src/v2/ui/AndroidApp.tsx`：曲库、社区、我的、主题状态、页面导航、预览样例与导入流程。
- 新建 `src/v2/ui/android.css`：安卓专属设计令牌、组件样式、断点、安全区和深浅主题。
- 修改 `src/v2/ui/libraryStore.ts`：为曲库检索增加汉字、无声调全拼和首字母匹配；维持原有存储行为。
- 修改 `src/v2/ui/EditorApp.tsx`：增加安卓播放器入口/外壳、来自安卓曲库的加载回调、紧凑播放控制与设置面板；播放内核仍使用已有实现。
- 修改 `src/v2/ui/ScoreCanvas.tsx`（仅在触控行为需要时）：为安卓触屏的谱面点击定位与双指缩放补充明确的交互回调，保留桌面画布默认行为。
- 修改 `src/v2/ui/editor.css`：只增加安卓播放器所需的入口样式隔离，不调整桌面现有页面布局。
- 修改 `android/app/src/main/java/com/windscore/app/MainActivity.kt`：冷启动加载 `android.html`，保留 WebView 文件选择器与系统返回能力。
- 新建 `docs/superpowers/plans/2026-10-20-android-independent-app.md`：本计划；中文产品规格仍以 `docs/superpowers/specs/2026-10-20-android-app-design.md` 为准。

## 视觉验收标准

- 形成有品牌辨识度的安卓视觉系统：主辅色、背景层级、文字层级、字号、圆角、阴影、图标线宽、触控尺寸和间距由 CSS 变量统一控制。
- 曲库页的搜索、收藏筛选、歌曲信息层级清楚；卡片有细腻但克制的状态反馈，避免桌面工具栏缩放或默认 HTML 控件拼接感。
- 播放页在练习/演出环境中优先保证谱面面积、控制清晰度和对比度；隐藏控制条后不留下遮挡，深色主题仍保持谱面可读。
- 手机窄屏、手机横屏、平板竖屏与平板横屏均使用合适的留白、导航密度和内容宽度；触控目标至少 44 CSS px，适配刘海/系统安全区。
- 明暗主题覆盖所有安卓页面、对话框、底部表单和播放控件；首次使用跟随系统，用户切换后保存本地偏好。

## 边界

- 本计划不增加账号注册、社区动态、曲谱编辑、对轨或导出功能。
- 安卓视觉仅作用于安卓独立入口，桌面与原浏览器页面沿用现有界面。
- 浏览器预览通过 URL 参数启用，样例与演示操作不污染浏览器已有曲库。
- 视觉验收以浏览器多尺寸实机模拟和人工交互检查为准；最终 Android 壳验证可用构建检查，不要求反复使用真机。
