# 大曲库性能优化

## 已确认方案

安卓曲库改为虚拟列表：数据与搜索覆盖全部曲目，仅渲染视口及上下缓冲区，保持连续滚动、不分页。伴奏按打开的曲目加载。缓存汉字、全拼与首字母索引，避免输入时反复转换。

## 实施步骤

1. 新建 `AndroidSongList.tsx`，承载曲库行和虚拟窗口；响应滚动、横竖屏及容器尺寸变化，保留曲目打开、收藏状态和菜单操作。检查列表首尾、筛选后范围、返回滚动位置。
2. `libraryStore.ts` 缓存搜索索引，并校验曲名与标题变化后更新。`AndroidApp.tsx` 将排序从每次搜索中移出，只在曲库变化时重排。
3. 更新样式与项目地图；运行类型检查、浏览器和 Android 构建，并在浏览器检查大曲库渲染数量、滚动、全库搜索和收藏。

## 跨端范围

- Android 与浏览器安卓入口共用虚拟列表。
- 浏览器 PC、Android、Tauri 共用搜索缓存，不更改存储格式与检索语义。
- PC 曲库包含首字母分组跳转，此次保留其独立列表布局；原生壳和伴奏解码逻辑不变。
- 不修改无关 BPM 算法，不运行无关测试套件。
