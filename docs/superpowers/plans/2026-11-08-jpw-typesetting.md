# JPW 印刷简谱与歌词标点实施计划

目标：在共享排版内核中接近 JPW.jpg 的字体、拍组密度、歌词贴合与行间留白；修复标点丢失且不消耗额外音符。用户已批准上一轮分析方向并要求实施。

约束：保留两端对齐、已有数据、显式换行、歌词空位、五线谱和多声部对齐；不修改音高时值。浏览器、Android、Tauri 与 PDF/PNG/SVG/视频共用实现。无关首页/曲库/帮助入口不改业务。

- [x] 歌词：先复现中文标点被输入分词过滤；标点附着歌词字，保存格式不变；测试输入、顺延、往返。
- [x] 字体：离线打包授权允许的印刷数字与宋体类中文字体；启动等待字体加载；布局与绘制共用数字度量。
- [x] 横向：为短音设置较紧自然宽度，拍组间优先吸收拉伸；歌词左右墨迹参与防碰撞，标点不改变汉字对音中心。
- [x] 纵向：首段歌词与段距分离；普通简谱逐行计算行带高度，更新命中、分页与播放读取行带的路径；五线谱/总谱保留适用的对齐机制。
- [x] 视觉：浅色谱面黑墨、短弧按跨度决定形状；同曲样本在桌面和窄屏渲染，验证标点、两行歌词、长音和跨行弧线。
- [x] 验证：相关 Node 回归、类型检查、浏览器构建、Android 构建与响应式预览、桌面构建；检查实际导出。
- [x] 交付：npm run version 一次，同步版本和锁文件；APK/EXE 放 artifacts/releases，保留旧版；记录实测与未验证边界。
