# WindScore 重奏与 JPS 简化开发规格

依据：用户已批准功能对照文档中的方向及重要性排序，并要求开始开发。

## 本轮交付

完整声部制谱：新增、命名、排序、删除声部；总谱/当前分谱视图；点击总谱内音符切换所属声部；编辑、撤销、保存和恢复保留全部声部。新增声部按现有小节创建休止符，不复制旋律。

总谱采用左侧声部名称与连谱号，各声部在同一小节内按共同起始时值对齐；整组共同换行、分页。声部小节长度或演奏顺序不一致时明确提示，避免不同声部在播放中错位。

同时播放各声部，支持静音、独奏、音量，所有声部显示当前播放音符。分谱显示不改变合奏设置。PDF 与视频共享总谱排版，导出弹窗可选择总谱或某个分谱。

JPS 新增显式 `@format 3`、`@part 编号 "名称"`，旧文件保持原规则。新版本增加 `/`、`//`、`///` 短写、自动拍组与 `<3: 1 2 3>` 均分一拍三连音省写。显式时值与分组继续有效。复合拍组按三个八分音符聚合。

## 架构

现有 Score.events/groups 保留为第一声部的唯一数据源；part 保存该声部身份与试听设置，parts 保存其余声部。编辑器提取当前声部投影，提交时合回整谱。声部事件和组使用独立 ID 命名空间，连线保持声部内部引用。

共同横向坐标由各声部同一小节的起始 ticks 与字形占位共同计算，复用现有绘制、连音线与技法算法。总谱的所有声部行归属于同一个 system，分页按 system 分配。

首声部的反复/跳房子与跳转是全谱演奏顺序；映射到其他声部对应小节边界后一起展开。声部缺少小节或小节时值不一致必须在试听前提示。

## 交付检查

进行 TypeScript 编译与构建检查，检查改动差异和界面显示；不新增或运行测试套件。保留当前未提交的用户改动，不自动提交。局部临时声部、歌词、SVG、跨音力度范围属于下一批功能，不纳入本轮完整重奏的数据模型。
