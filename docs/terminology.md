# WindScore 界面术语表

> 来源：`docs/hallmark修改建议.md` 第五节（用户 2026-11-08 拍板采用）。
> 本文件是**用户可见文案的唯一叫法来源**；改文案前先查这里，改完同步 `scripts/v2-test.ts` 的 `[界面术语与文案]` 断言。
> 约束：DSL 记号、数据字段名、函数名、CSS 类名不受本表约束，只管界面上用户读到的字。

## 页面与入口

| 概念 | 唯一叫法 | 不再使用 | 说明 |
| --- | --- | --- | --- |
| 播放首页（`play.html` 首屏） | **动态谱演奏** | 动态谱首页（作返回目标时） | 返回按钮写目标页正式名，不用简称 |
| 对轨页（`align.html`） | **伴奏对轨** | 动态谱生成、对轨（作页面名时） | 首页入口与站内标题同名 |
| 曲库页（`library.html`） | **曲库** | 曲库管理、曲库查询、曲库制作 | 只读态写 **曲库（只读）**；「曲库制作」这个页面不存在，禁止再用来指路 |
| 简谱编辑页 | **简谱编辑** | 写谱器 | |

## 对轨概念

| 概念 | 唯一叫法 | 不再使用 | 说明 |
| --- | --- | --- | --- |
| 谱面小节线 ↔ 音频时刻的手动对应点 | **对齐点** | 锚点、绑定点 | 「绑定」只作动作动词（绑定对齐点），不作名词 |
| 由对齐点与 BPM 推导、画在波形上的拍格线 | **网格线** | 节奏线 | 与「对齐点」是**两个对象**：网格线可点选 / 拖动整组平移，对齐点是用户手动绑定的对应点。建议表把两者并入一条，这里按产品语义拆开，避免「拖对齐点」被误解为移动绑定关系 |

## 记谱概念

| 概念 | 唯一叫法 | 不再使用 | 说明 |
| --- | --- | --- | --- |
| 自由拍子 | **散板** | サ、散（作按钮文字时） | DSL 记号 `散` 与国标里的「サ」字形保留在实现层与说明文字里 |
| 小节线上的排版属性 | **此线后换行** | 换行（指属性时） | 与下面的插入动作区分 |
| 插入换行记号 | **插入换行** | 换行（指动作时） | |
| 反复段次记号 | **跳房子** | 房子、`[1]` 作名称时 | `[1]` 仍是按钮上的具体编号，可保留 |
| 导入谱面 / 打包 | **导入乐谱** | 从本地导入乐曲 | 与「局域网传曲」各管一个入口 |
| 手机从电脑传谱 | **局域网传曲** | 从网络传入乐曲 | |

## 落地纪律

- 文案里出现「请去某页 / 请点某按钮」时，目标必须是当前界面真实存在的控件名；改名同步改指引。
- 帮助文档 `docs/user-guide.md` 与界面文案以**实际行为**为准，任一侧改动都要核对另一侧。
- 每批改动后跑 `npx tsc --noEmit`、主回归与 `npm run build`；源码断言防止术语漂移。
