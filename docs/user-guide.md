# WindScore 使用帮助

从写谱到伴奏对齐、曲库演奏和分享。日常制谱与播放使用本机数据，无需账号。帮助内容对应当前工作区功能。

各页面的「帮助」入口位于顶部菜单或工具栏；首页按钮带问号图标。简谱编辑底部只保留状态信息，歌词通过声部栏的「词」标签输入。

## 快速开始

### 选择入口

| 入口 | 用途 |
| --- | --- |
| 动态谱演奏 | 搜索曲库、收藏曲目，打开动态谱演奏 |
| 简谱编辑 | 写简谱、编辑重奏与歌词、导出 PDF |
| 动态谱生成 | 在独立页面载入伴奏、标定对齐并打包动态谱 |
| 曲库管理 | 导入曲谱、管理曲库、打包分享和配置存储位置 |
| 帮助 | 分类查看使用步骤、快捷键和 JPS 写法 |

### 第一次写谱

1. 从首页进入「简谱编辑」，点击「新建」，或选择一份示例乐谱学习。
2. 点击谱面标题旁的配置图标，填写曲名、调号、拍号、速度和说明。
3. 在谱面上点击插入位置，用数字键输入音符，使用右侧面板调整时值和记号。
4. 观察顶栏的「谱面校验」，修正小节拍数与连线等问题。
5. 点击「保存」得到 .jps 文件。浏览器版通常下载文件；桌面版使用系统保存对话框。
6. 若要进入曲库，到「曲库管理」点击「导入 .jps」。若包含伴奏，从首页进入「动态谱生成」，完成标定后点击「打包」，再导入 .wspack。

### 从已有文件开始

- 编辑页「打开」载入 .jps 或文本谱面；源码视图也可以粘贴符合规范的 JPS 内容。
- 曲库页「导入打包」用于 .wspack，包含曲谱、分轨音频和对轨标定。
- 曲库页「导入 .jps」只收录谱面，伴奏需要另配。
- 示例谱包含普通单旋律、反复、二重奏、变拍号与力度范围、多段歌词，以及「小星星（四声部示例）」的主旋律、和声、分解和弦与低音。

## 记谱编辑

### 曲目信息与版式

点击谱面标题旁的配置图标打开曲目信息，设置曲名、调号、拍号、速度、音色、标题下说明与谱头右侧说明。音色填写 MIDI 编号；字号和字间距保存到 JPS。点击谱面音符回到音符属性面板。

### 光标、选中与选区

点击音符会选中该音；输入数字将替换它的音级。点击音符之间的空隙进入插入状态；输入数字会新增音符。底部状态栏显示当前音符数量、事件数量、光标与选区。

- 拖拉跨过多个音符建立选区，拖到谱面边缘会自动滚动。
- Shift + 点击选中到此处；Shift + 左右方向键扩展选区。
- 选区可以复制、粘贴、删除、修改时值和添加连音线。
- 多选时右侧「总时值」将该范围中的音均分成所选总时值，不是把每个音都改成该时值；普通选区拍组的总时值上限是一拍。
- 音符间距滑杆调节编辑视图密度；曲目信息中的字号和字间距会写入文件。

### 音符与时值

数字 1–7 是音符，0 是休止符。选中音符后，右侧面板可以调整音级、八度、变音记号、时值和附点；选区操作作用于所选范围。

| 例子 | 含义 |
| --- | --- |
| `5` | 一拍的 sol |
| `5-`、`5--`、`5---` | 两拍、三拍、四拍 |
| `5.`、`5..` | 单附点、双附点 |
| `5/2`、`5/4`、`5/8` | 半拍、四分之一拍、八分之一拍 |
| `5^`、`5v` | 高八度、低八度，可叠加 |
| `#5`、`b5`、`♮5` | 升、降、还原 |
| `0-` | 两拍休止 |
| `8` | 隐藏休止（占位不画，写法同 `0`：`8/2`、`8.`、`8--` 均可），行中混排时给未进入的声部留空拍 |

输入 5 后连按两次 -，得到 5--，表示三拍。按 ^、v、.、t 等快捷键时，修改紧挨光标左边的那个音；选中状态下按界面光标提示确认编辑对象。

### 短音分组与连音符

拍内短音用拍组连接减时线。可通过编辑面板处理拍组，或在源码用 `<3/2 5/2>` 表示两个八分音符。JPS 3 普通短音会自动按拍生成组，显式 `< >` 可覆盖分组。

三连音、六连音是节奏连音符，使用带数字的拍组，例如 `<3: 1/3 2/3 3/3>`。它与音符上方的连音弧线不同：弧线表示连贯演奏，连音符表示时值分配。

### 连音线与延音线

先选中至少两个音符，再使用面板连线操作或 Ctrl+L 添加连音线。连线可以跨小节和谱行；两端必须是音符。连音线在深色下为金黄色、浅色下为深金色。

源码中 `(5 6 5)` 表示连音线；`5~5` 表示相同音高的延音线。想写三拍长音时，直接使用 `5--`。

### 倚音与演奏记号

选中主音，在右侧设置前倚音或后倚音，可配置音级、八度和变音。界面最多配置三颗；倚音不占主音时值，也不占歌词位置。

常用记号包括吐音 T/K、换气、断音、保持音、重音、延长音、花舌、打音、波音、滑音和弯音。右侧面板按当前选中对象显示可用操作。记号的谱面显示与合成音表现不完全相同，合成试听用于核对音高、节奏与演奏顺序。

### 力度与转调

音符可设置 pp、p、mp、mf、f、ff，以及单音渐强或渐弱标记。选中至少两个音符，可添加跨音渐强/渐弱范围，跨行时继续显示。

转调从被设置的音符开始生效，例如 `转1=G 6 6`。渐强/渐弱范围目前是谱面表达，不生成合成器音量渐变。

## 快捷键

快捷键在记谱区域使用；输入框中仍按普通文本编辑处理。

| 按键或动作 | 作用 |
| --- | --- |
| 1–7 | 输入音符；选中音符时替换音级 |
| 0 | 输入休止符 |
| \| 或反斜杠 | 输入小节线，连按两次得到终止线 |
| - | 给光标左边的音增加一拍 |
| ^ / v | 升 / 降八度 |
| . | 附点循环：无 → 单 → 双 → 无 |
| t | 吐音开关 |
| 左 / 右方向键 | 在音符和插入位置之间移动 |
| Shift + 方向键 / 点击 | 扩展选区至该位置 |
| 拖拉选区 | 拖到边缘自动滚动 |
| Backspace / Delete | 删除 |
| Esc | 取消选区或退出对轨配对；帮助窗口内关闭帮助 |
| Ctrl+Z | 撤销 |
| Ctrl+Shift+Z / Ctrl+Y | 重做 |
| Ctrl+C / Ctrl+V | 复制 / 粘贴选区 |
| Ctrl+L | 给选区加连音线 |
| Ctrl+S | 保存 |

原底部速查示例：输入 `5` 后连按 `--`，得到 `5--`（三拍）。

## 小节与演奏结构

### 小节线与校验

点击小节线，右侧会显示小节设置。可以切换普通线、终止线、反复起止、反复遍数、跳房子和跳转记号。

每小节总时值应符合拍号。4/4 为四个四分音符拍，3/4 为三个，6/8 为六个八分音符。弱起是开头不满的小节，需与结尾互补；在源码中用 `\|{partial}` 标记。

顶栏显示校验状态；有问题时点击查看具体信息。重点检查多拍/少拍、非法拍组、连线引用、反复配对，以及不同声部对应小节是否一致。

### 反复和跳房子

反复开始为 `\|:`，结束为 `:\|`，结束线可设置反复次数。两者应配对。

房子挂在所罩小节的左墙小节线上，向右延伸到反复结束或下一段房子。先点击左墙，再选 [1]、[2] 或 [3]。源码在小节线之后写房子号，例如 `\| [1]`。

完整小节选区也有反复与房子的区间操作，可一次设置所选段落。操作会调整段落边界的小节线，完成后查看谱面与演奏顺序。

播放会按反复结构演奏。播放页可以切换「原谱」和「展开反复」；展开显示演奏顺序中的每一遍，导出也跟随当前显示的版本。

### D.S.、D.C.、Fine 与 Coda

选中小节线，在右侧的「跳转记号」设置跳回目标 𝄋、D.S.、D.C.、To Coda、Coda 或 Fine。标记挂在小节线后面。

- D.S. 跳回 𝄋；D.C. 跳回全曲开头。
- 跳回后的演奏可由 Fine 结束，或由 To Coda 跳至 Coda。
- 操作后查看演奏顺序和校验提示，确认标记的组合符合想要的路径。

### 中途拍号与换行分页

点击小节线或旁边的变拍号数字，设置「此线之后的拍号」。拍号从下一个小节开始生效。例如上 3 下 4 是 3/4 拍：四分音符为一拍，每小节三拍；上 6 下 8 是 6/8 拍：八分音符为一拍，每小节六拍。重奏总谱中的结构由首声部控制，在首声部的小节线处修改。

「此线之后的排版」可选自动、换行、分页。分页同时换行，PDF 从下一整组声部开始新页；PNG/SVG 长图保留换行，不增加纸页空白。源码中的普通文本换行不会强制谱面换行。

编辑谱面中，小节线末尾的 `↵` 表示强制换行，`↵页` 表示强制分页。这些是编辑辅助标记，不显示在正式导出中。光标跨行或跨页移动到可视区域之外时，谱面自动滚动到当前编辑位置；歌词格仍通过自己的输入定位滚动。

## 重奏制谱

### 创建与管理声部

在声部栏点击「新增声部」。单旋律也可发展为重奏；声部标签决定编辑对象。

- 点击标签选中声部；只有选中的声部显示配置和删除图标。
- 配置中设置名称、音量、静音和是否独奏；独奏时仅未静音的独奏声部发声。
- 删除需要确认，并保留至少一个声部；编辑操作可以撤销。
- 把一个标签拖到另一个标签上，两个声部互换位置，谱面次序也随之调整。
- 「总谱」查看全部声部；「当前分谱」只查看当前声部。

### 共同节奏与总谱规范

各声部在同一小节中按时间对齐，长音和长休止的每条增时线也对齐对应拍位。点击增时线会选中所属音符。左侧显示名称和连接符；PDF 按整组声部分页。对应小节应具有相同的时值与数量。

**首声部控制全谱结构**：全局调号、拍号、速度共享，反复、跳房子、弱起、跳转、变拍号及换行/分页由首声部统一定义，其他声部继承。拖拽交换首声部时，请再次核对这些结构。

不同声部可以拥有自己的旋律、记号和歌词。合成播放同步演奏全部声部，使用声部音量、静音和独奏设置。真实分轨伴奏的开关在音频区域单独控制。

### 总谱与分谱导出

导出弹窗的「导出内容」选择全部声部或某一分谱，PDF、图片和视频共用选择。总谱显示左侧连接符，分谱保留对应声部信息。

局部复调、临时伴奏，以及行中临时增加或隐藏声部尚未实现。

## 歌词

### 输入多段歌词

点击「新增声部」，在类型中选择「歌词」，填写名称并选择关联演奏声部。添加后声部栏出现带「词」标记的标签，点击标签即可在谱面输入。每个演奏声部最多六条歌词行；歌词行不发声、不需要拍数或小节线。

1. 直接点击音符下方的歌词格输入。一次输入中文词句（或粘贴文字）会自动逐字分配到连续主音，例如「什么」变成「什」「么」，光标移到后面的格子。多出的字会让后续已有歌词顺延。
2. 新输入一个字后，按空格确认并移动到下一个主音；在空白格按空格即跳过该音。若发现两个字之间需要留空，回到后一个字的格子按空格，在它前面插入空位，后续歌词一起顺延，例如「什／么」变成「什／空／么」。无需输入 `_`。
3. Tab、Enter 或右方向键到下一音，Shift+Tab 或左方向键到上一音。到末音后停留，不循环覆盖开头。
4. 小节线、休止符、前后倚音自动跳过；跨小节和换行时会滚动到输入位置。
5. 遇到前奏、间奏，点击声部栏的歌词标签后，直接点击歌词开始处的格子或对应音符即可跳过去。
6. 中文输入法选字期间，空格和方向键交给输入法；词句在完成选字后再分格。粘贴文字中的空格占一个歌词位置，中文逗号、句号、问号、叹号、顿号、分号、冒号不占位置；连续非中文文字按一个词处理。
7. 退格键删除选中的字，后面的歌词向前补齐；在空白格或一个字前的光标位置按退格，删除前一位置（字或空位）。删除后光标留在删除位置，可以连续向前退格，开头不再后退。可用顶部「撤销」恢复。

单字修改后按空格或离开该格即写入谱面，多字词句自动分格写入。若剩余音符不足，或顺延会挤掉末尾已有歌词，操作会提示且不写入，请补充音符或整理后续歌词。点击「结束歌词输入」或按 Esc 回到写谱。选中的歌词标签显示配置和删除按钮。配置可以修改行名、关联声部；更换关联声部按主音顺序对应，目标音符不足时提示并保留原歌词。删除前确认，输入、补空位和删除均可通过编辑器「撤销」恢复。

已有歌词自动显示为歌词行；没有歌词时通过「新增声部」选择歌词类型创建。若整个声部暂无音符，请先点击演奏声部标签写好旋律。

### 编辑后的对应关系

歌词附着在音符上，复制、删除和反复展开会随音符处理。新插入的音默认无歌词，不会挤走其他音的歌词；必要时点击歌词行整理对应关系。拖拽交换演奏声部时，关联歌词标签和谱面文字一起移动。

歌词基础字号从 12 增大到 16，段间距从 18 增大到 24，随谱面缩放一起变化；编辑、播放、PDF、PNG、SVG、视频共用这一绘制样式。源码或旧文件中保留的一音多字仍可显示，长词组会在本音格宽内压缩，可增加字间距改善阅读。歌词会增加必要的行距，避免与力度或下一声部重叠。

```text
@format 3
@beat 4/4

1 2 3 4 ||
歌词1: 春 风 _ "hello world"
歌词2: 星 光 照 路
```

源码仍使用逐音歌词语法：空格分词、`_` 留空、`|` 可辅助分隔小节，带空格的词组用双引号。界面输入无需记这些符号。自定义行名在关联的 `@part` / `@mix` 后保存，例如 `@lyricNames ["第一段", "第二段"]`；空歌词行也会保留。

## 伴奏对轨

### 准备音频

从首页点击「动态谱生成」进入独立的伴奏对齐页面。页面接续上次使用的曲谱，也可点击「打开」选择 .jps；曲库管理中点击某首曲目的「对轨」，会带着该曲目进入生成页，并恢复已有伴奏与标定。简谱编辑页只负责记谱，不再提供记谱/对轨切换。

对轨时谱面只读，波形和音频设置成为主要操作区域。可载入一条伴奏，也可以多条分轨，逐条开关音频。WAV 载入后会压成 MP3 入库。

人声、鼓、贝斯、其他乐器等分轨应来自同一版本歌曲，并保留相同音频起点。音频分轨与乐谱声部是不同对象：前者控制真实录音，后者控制按谱合成。

### 估计速度与波形网格

导入后程序估计 BPM 和网格位置。试听并观察网格是否落在实际节拍上；估成倍速或半速时，使用 ÷2 / ×2 调整。自动估测是起点，真实歌曲仍需要锚点校准。

「重新自动对齐」可重新估测并尝试对齐。谱面 BPM 管按谱合成的速度，音频 BPM 管伴奏网格，两者独立；改变其中一个不会自动改变另一个。需要手动微调时，可调整恒定 BPM 参数和音频原点。

可缩放波形，并使用网格吸附；网格尚未对准时先关闭吸附，避免点击被吸到错误拍点。

### 用锚点对齐

1. 在波形上点击一个已知拍点。
2. 在谱面上点击与其对应的小节线，建立绑定。谱面最左侧「开头」靶标对应第零拍。
3. 再在后续位置绑定第二个锚点；两个以上锚点形成分段变速映射。
4. 分别试听开头、中间和结尾，逐步添加必要锚点，使播放指示与音频一致。

也可使用「快速锚定」或把选中的音对到波形位置，处理某个音的精细对齐。锚点列表可查看、删除或清除标定。按 Esc 可退出等待谱面点击的配对状态。

### 保存与分享

对轨信息按当前曲目保存。点击顶栏「打包」，导出包含谱面、伴奏和标定的 .wspack；到曲库「导入打包」收录，之后可在动态谱演奏页播放。

普通 .jps 文件不包含伴奏与对轨标定。替换曲谱或音频后应重新核对锚点，避免沿用不匹配的标定。

## 曲库与存储

### 导入与管理

曲库页支持批量导入 .jps 或 .wspack。列表显示曲名、调号、拍号、BPM、小节数和音符数；无法解析的曲谱会标出状态。

- 点击曲目进入播放；使用编辑操作进入制谱。
- 重命名用于管理曲库条目；谱面内部的标题在曲目信息里修改。
- 打包分享输出 .wspack，便于传给其他用户。
- 删除需确认；请先保留需要的 JPS 或打包备份。

### 配置曲库位置

首次使用时按页面提示配置曲库。桌面版可在曲库页打开文件夹或更改位置；支持文件夹访问的浏览器可选择真实文件夹并重新连接。暂不配置时使用浏览器本地存储。

曲库文件夹包括：library.json（曲目与谱面）、align.json（对轨标定）和 audio 文件夹（分轨音频）。迁移时复制整个曲库文件夹；单首曲目迁移可用 .wspack。

浏览器可能需要重新授权文件夹访问。页面提示断连时点击「重新连接曲库文件夹」；不要仅复制 JPS 后期待伴奏自动出现。本地存储会受浏览器清理影响，重要曲目应保留文件备份。

## 动态谱演奏

### 找到曲目

从首页进入「动态谱演奏」。首页显示最新动态、我的收藏、全部曲目和最近搜索。

- 输入歌名或标题，回车或点击「搜索」。
- 使用首字母索引定位曲目。
- 点击星号收藏或取消收藏；常用曲目可从收藏区域打开。
- 最近搜索可单条删除或清空。

### 播放与观看

进入曲目后点击播放/暂停。可切换「伴奏」与「合成音」；没有可用伴奏时，伴奏选项不可用。

- 伴奏按对轨标定驱动播放位置；合成音按曲谱音高和时值演奏。
- 音轨开关可单独控制真实分轨，「全放」打开所有分轨，「无人声」按文件名识别人声轨并关闭它们。
- 「原谱 / 展开反复」切换记号谱与按演奏顺序铺开的谱。
- 「光标」跟随当前音，高亮条显示当前行播放进度；谱面自动滚动跟随。
- 字号和字距是播放观看偏好，只改变显示，不修改 JPS 文件；恢复按钮回到谱面设定。
- 重奏可查看总谱或当前分谱；按当前视图选择导出内容。

编辑页试听支持跟随当前光标起播，状态栏显示起播位置。播放中的指示与真实伴奏不一致时，到对轨页调整标定。

## 导出与分享

编辑页点击「导出 PDF」，播放页点击「导出」，都会打开同一导出窗口。窗口按 PDF、视频、图片分类；重奏可选择全部声部或某一分谱。编辑页源码有未应用改动时，导出前会先解析，错误需要修正。

### PDF

- A4 纵向或横向，150 / 300 dpi。
- 沿用当前谱面的字号、字间距、音符间距和每行小节布局，导出时不重新断行，也没有独立的导出字号设置。纸张宽度不同会整行等比适配，字形与间距的比例保持一致。
- 导出窗口显示实际 PDF 页面预览，可点击上一页、下一页检查。横向/纵向纸张影响整页大小与分页；150/300 dpi 只改变清晰度，不改变每行小节数。
- 要调整字号或每行小节数，先在谱面中调整字号、字间距或音符间距，再导出。可选择是否包含标题和显示小节号；编辑光标、换行提示和设置按钮不印入 PDF。
- 实时显示预计页数；每页页脚为「歌名-页号/总页数」。
- 强制分页标记生效；总谱整组声部一起分页。
- 整组声部过高时，在谱面中减小字号、增加每行小节数，或导出分谱。

### PNG 与 SVG

在「图片」页选择 PNG 长图或 SVG 矢量图片，宽度 720 / 1080 / 1440，可选深浅色、标题和小节号。

PNG 便于发送和预览；SVG 由文字和矢量路径组成，放大不失真。SVG 不嵌入字体，在其他设备上的外观可能受字体影响。两种图片都保留换行，分页不生成空白纸页。

过长 PNG 超出画布限制时，改用 SVG 或分页 PDF。

### 视频

可选择手机、平板等横竖屏比例，短边 720 / 1080 / 1440，帧率 25 / 30 / 60，并指定小节范围。

- 选择伴奏或合成音；伴奏需要可用音频和标定。
- 可选浅色或深色，谱面按画面比例重新排版。
- 离线编码，画面随播放位置滚动；进度显示在导出窗口。
- 优先输出 MP4；编码器不支持时可转用 WebM，具体能力取决于运行环境。
- 导出期间保持页面打开；取消后等待收尾。

### 打包与谱面文件

.jps 是可编辑的文本谱面。.wspack 用于完整分享曲谱、伴奏和标定。PDF/图片便于看谱与打印，视频便于展示动态谱；它们不能替代可编辑原文件。

## JPS 源码

### 基本结构

切换到「源码」可编辑纯文本。点击「应用」重新解析；切回简谱也会自动应用。解析错误时保留原谱面，修正后再应用；「丢弃改动」恢复当前谱面的源码。

```text
@format 3
@title 我的曲谱
@key 1=C
@beat 4/4
@bpm 90

1/ 2/ 3 4 5 | (6 5 3 2) ||
```

### 谱头参数

| 参数 | 用途 |
| --- | --- |
| @format 3 | 启用重奏、时值短写、自动拍组和歌词 |
| @title | 曲名 |
| @key | 调号，例如 1=C、1=G、1=bB |
| @beat | 全局拍号，例如 4/4、6/8 |
| @bpm | 速度 |
| @patch / @patchName | MIDI 音色号 / 说明 |
| @sub | 标题下的说明 |
| @note | 谱头右侧说明，多行分别写 |
| @size / @space | 谱面字号 / 字间距 |

编辑器默认使用新版简洁语法，无需开关；新建空谱的源码也会自动带上 @format 3。没有这行的旧文件先按旧语义解析，进入编辑器后自动转换为新版表示，保留已有音高和时值，保存时写出 @format 3。元信息每行一条，音符 token 用空格分隔；`//` 开头是注释。

### 记号速查

| 写法 | 含义 |
| --- | --- |
| `5/`、`5//`、`5///` | JPS 3 中分别等价 5/2、5/4、5/8 |
| `<1/2 2/2>` | 明确拍内组 |
| `<3: 1 2 3>` | JPS 3 的一拍三连音短写；复杂时值需明确写出 |
| `(1 2 3)` / `5~5` | 连音线 / 延音线 |
| `{65}3` / `3{65}` | 前 / 后复倚音，内部连写 |
| `5t`、`5k`、`5V` | 吐音 T、吐音 K、换气 |
| `mf 5` / `转1=G 5` | 力度 / 从该音起转调 |
| `cresc[ 1 2 3 ]hairpin` | 跨音渐强；dim 为渐弱 |
| `\| 拍3/4 换行` | 下一小节起改拍号并换行 |
| `\| 分页` | 下一组从新页开始 |
| `\|:`、`:\|3`、`\| [1]` | 反复开始、演奏三遍的结束、第一房子 |
| `$s $ds $dc $t $x $f` | 𝄋、D.S.、D.C.、To Coda、Coda、Fine |

独立换气符号 ' 不再支持，使用音符后缀 V。跳转记号实际作为独立 token 挂在小节线后。三连音短写须正好三个音、全部省略时值且无附点/增时；旧语法不会自动获得此含义。

### 重奏与歌词源码

```text
@format 3
@title 二重奏
@key 1=C
@beat 4/4
@bpm 90

@part 1 "主旋律"
@mix 1 on all
1/ 2/ 3/ 4/ 5 5 | 6 5 3 2 ||
歌词1: 春 风 吹 过 山 川 云 _ 海 风

@part 2 "低声部"
@mix 0.8 on all
1v--- | 5v--- ||
```

@part 后的内容属于该声部，直到下一声明。编号为唯一正整数，声明顺序决定总谱次序。@mix 为音量、on/off（发声/静音）、all/solo（普通/独奏）。歌词1: 到歌词6: 各段号不能重复，内容从该声部第一个主音对齐。

## 常见问题

### 音符输错位置怎么办？

看底部状态：选中音符时数字替换音级，插入点时新增音。用鼠标或左右方向键移动光标，Ctrl+Z 撤销。

### 为什么某小节提示拍数不对？

按拍号合计时值，检查附点、短音与增时线。6/8 是三个四分音符时值，通常按三个八分音符成组。多声部还要检查每个声部的小节长度是否一致。

### 为什么找不到伴奏，或只听到合成音？

普通 JPS 不包含音频。导入完整 .wspack，或到对轨页载入音频并标定。曲库文件夹断连时先重新连接；音频缓存缺失时需重新导入或载入。

### 为什么播放指示越放越偏？

自动 BPM 可能估为倍速或半速，歌曲也可能变速。检查 ÷2 / ×2 和网格拍点，再绑定分布在不同段落的锚点。

### 为什么歌词挤在一起？

确保每个字/词有空格分隔，延音位置使用 _。长词组受音符格宽限制，增加字间距或让一行容纳更少小节。

### 为什么重奏或 PDF 显示空间不足？

先确认各声部对应小节一致，再在谱面中调整字号与间距。PDF 保留当前每行内容并等比适配纸张；多段歌词增加行高，过多声部可能超过一页的可用高度，可增加每行小节数或导出分谱。导出窗口的逐页预览可提前查看结果。

### 如何迁移到另一台电脑？

复制完整曲库文件夹，或逐曲导出 .wspack 再导入。仅迁移 JPS 不会带走音频和标定。

### 哪些功能还没有完成？

局部复调、临时伴奏、行中声部混排，以及复杂技法、房子和文字的全面碰撞避让仍待开发。渐强/渐弱范围目前只作记谱，不控制合成器音量曲线。
