# WindScore 简谱转录与生成

你的任务：把简谱图片（或用户描述的旋律）转录成 `.jps` 内码文件，**并用校验器证明它是对的**。

## 两条铁律（先读，再干活）

1. **模型只负责「看」，不负责「写语法」**：识别结果一律先写成 `tools/README.md` 定义的 JSON，再由 `tools/json2jps.mjs` 转成 .jps。**禁止手写 .jps token**——手写是语法漂移和时值错谱的第一来源。
2. **一切结论必须过校验器**：`json2jps` 零拍数告警 **且** `validate.mjs` PASS，二者都过才算完成。不许跳过校验，也不许凭感觉认为「应该没问题」。

## 工作流（v2：框架先行 → 分段识别 → 小节级回压）

### 第 1 步：读语法与工具说明

生成任何内容之前，先完整阅读：

- `reference.md` —— .jps 语法的完整参考（音符构造、拍内组、三连音、连音线、反复、倚音、转调、段落标注）
- `tools/README.md` —— JSON 字段表、dur 速查表、两个工具的用法

### 第 2 步：第一遍读图——只定框架

只读并**复述给用户确认**：曲名、调号（1=?）、拍号、速度、共几小节、是否弱起、声部数。
读不出的信息（如速度）按风格合理估计并声明。**拍号是后面每一小节的硬约束，必须最先钉死**——它错了整谱全错。

### 第 3 步：预处理与分段识别

- 长图、字小、八度点 / 附点看不清 → 用 `tools/preprocess.mjs` 放大（必要时按行切条、二值化）：
  ```bash
  node tools/preprocess.mjs 原图.png out --scale 2.5 --rows 4
  ```
  之后逐个读 `out-r1.png …`，不要读原图。
- **逐段识别**：每次只识别一行（或 2 个小节），避免整图一次读完细节丢失。
- **每段识别两遍**（或用两个不同放大尺度各读一遍）：结果一致才接受；不一致的段记入「待人工核对清单」，先按更有把握的一版写，**并在交付时明确列出**。
- 每段直接输出 `measures` 片段 JSON（字段表见 `tools/README.md`）。看到 `5-` 就写 `"dur": 2`，看到 `5.` 写 `"dur": 1.5`——**dur 速查表在 tools/README.md**。

### 第 4 步：转写

把全部小节拼成一个完整 JSON，运行：

```bash
node tools/json2jps.mjs 谱面.json > 曲名.jps
```

脚本会：检查字段合法性 → **逐小节拍数对账**（stderr 精确报「小节 N 合计 X 拍 ≠ 拍号，差 ±Y」）→ 生成 .jps。
退出码 1 = 有小节没对上。

### 第 5 步：小节级回压（本 skill 准确率的核心）

`json2jps` 报哪一小节拍数不对，就**只裁剪那一小节**（放大 3 倍）重新识别，替换该小节的 JSON 片段，重跑第 4 步。

- 不许整谱重认，也不许为了凑拍数凭感觉改时值——回去重看原图。
- 循环到拍数全对（退出码 0）。改两轮仍对不上的小节，进「待人工核对清单」并按最可能的一版交付。

### 第 6 步：终校验与交付

```bash
node validate.mjs 曲名.jps
```

必须输出 `PASS`。然后交付，附上：

1. 各小节拍数、拍内组数、是否弱起（一句话）；
2. **待人工核对清单**：两遍识别不一致的段、看不清的八度点 / 附点、仍未消掉的拍数告警；
3. 用户在 WindScore 程序中打开即可直接使用。

## 校验器的原理（为什么可信）

`validate.mjs` 内嵌了 WindScore 程序本身使用的解析器与全部不变量（不是重新实现），因此校验通过 ≈ 程序能无损打开：

- 解析错误 = 程序打不开
- I1–I5 = 程序的 BeatGroup / 连线不变量（编辑器里以"谱面校验"呈现）
- 小节拍数徽标 = 程序排版层的同一套校验（含弱起豁免逻辑）
- round-trip = 序列化再回读必须与解析结果完全一致

**`validate.mjs` 是构建产物**：程序解析逻辑（dsl.ts / edit.ts / ticks.ts）改动后，要在仓库根目录重跑 `npm run build:skill` 重新生成，否则校验器会悄悄落后于程序。

## 示例

`examples/songbie.jps` 是一首完整的 4/4 谱面（送别，12 小节，含拍内组、三处连音线、终止线）：

```bash
node validate.mjs examples/songbie.jps   # → PASS
```

转录时对照它的写法：组与连音线如何交叉（`<(3/2 5/2)>`）、长音增时线（`1--`）、高八度（`1^`）、附点（`1^.`）。段落文字标注写 `(前奏)`，左右括号记号写全角 `（ ）`。
