# WindScore 简谱内码（.jps）完整语法参考

`.jps` 是纯文本格式。整体结构：**头部元信息行 + 空行 + 谱面主体**。
谱面主体由记号（token）组成，**用空格分隔**；换行只是排版提示，不产生任何数据。`//` 开头是注释，`---` 单独一行会被忽略。

```
@title 送别
@key 1=C
@beat 4/4
@bpm 72
@patch 73

5 <3/2 5/2> 1^. 7/2 | 6 1^ 5- | 1-- 0 ||
```

## 1. 头部元信息（每行一个 @，全部可省略，有默认值）

| 行 | 含义 | 默认 | 说明 |
|---|---|---|---|
| `@title 名` | 曲名 | 未命名曲谱 | 自由文本 |
| `@key 1=G` | 调号 | 1=C | 写「1=调」形式 |
| `@beat 4/4` | 拍号 | 4/4 | 必须是 `N/M` 形式 |
| `@bpm 90` | 速度 | 90 | 正数 |
| `@patch 73` | MIDI 音色号 | 73 | 0–127 整数 |
| `@patchName 名` | 音色名称 | （无） | 自由文本，可省 |
| `@size 28` | 谱面字号（px） | 21 | 12–56；数字 / 附点 / 增时线 / 倚音整体随它等比缩放 |
| `@space 2` | 字间距（px） | 0 | -4–24；相邻记号之间的额外横向空隙，负数收紧 |

两条版式行通常**不需要写**——除非原图的字号明显偏大 / 偏小或排得很松 / 很紧，才按观感补上；程序会按它还原显示。

## 2. 音符记号的完整构造

一个音符 token 的语法（各段按此顺序）：

```
[变音记号] 音级 [八度点] [附点] [/除法] [增时线-] [~] [记号后缀]
```

- **音级**：`0`–`7`。`1`=do `2`=re `3`=mi `4`=fa `5`=sol `6`=la `7`=si。**`0` 是休止符**，不允许带记号后缀。
- **变音记号**（写在音级**左边**）：`#` 升、`b` 降、`♮` 还原。等价字形 `♯ ♭` 也可。
- **八度点**：`^` 高八度、`v` 低八度，可叠加（`5^^` 高两个八度）。可写在前导位或跟随位，`^5` 与 `5^` 等价，`#^5` 合法。
- **附点**：`.` 附点（×1.5）、`..` 双附点（×1.75），最多两个。
- **除法**：`/2` `/3` `/4` `/6` `/8`，表示 1/2、1/3、1/4、1/6、1/8 拍。**没有 /5、/7**。
- **增时线**：每个 `-` 加 1 拍，写在除法之后。`5-`=2拍、`5--`=3拍、`5---`=4拍。
- **延音线 `~`**：写在第一个音末尾，连接紧随其后**同音高**的音符：`1~1`。休止符不能接延音线。
- **记号后缀**（可多个连写）：

| 后缀 | 含义 | 谱面 |
|---|---|---|
| `!` | 断音 / 顿音 | 小圆点 |
| `=` | 保持音 | |
| `>` | 重音 | |
| `@` | 延长音 | ⌒ 加点 |
| `t` | 单吐 T | T |
| `k` | 双吐第二音 K | K |
| `V` | 换气 | V（**大写**，避免与低八度 v 混淆） |
| `r` | 颤音 | tr |
| `f` | 花舌 | * |
| `d` | 打音 | 扌 |
| `m` | 上波音 | ≈ |
| `w` | 下波音 | ≈（倒置） |
| `s` | 上滑音 | ↑ |
| `x` | 下滑音 | ↓ |
| `q` | 前弯音 | ↗ |
| `h` | 后弯音 | ↘ |

## 3. 时值速查表（默认拍号 4/4，1 拍为基准）

| 想要的时值 | 写法 |
|---|---|
| 4 拍 | `5---` |
| 3 拍 | `5--` |
| 2 拍 | `5-` |
| 1 拍 | `5` |
| 1.5 拍 | `5.`（附点四分） |
| 1.75 拍 | `5..` |
| 1/2 拍 | `5/2` |
| 1/4 拍 | `5/4` |
| 1/8 拍 | `5/8` |
| 1/3 拍 | `5/3`（三连音成员） |
| 1/6 拍 | `5/6`（六连音成员） |
| 3/4 拍 | `5./2`（附点 + 除法：附点乘在除法结果上，24×1.5=36 tick=3/4 拍） |
| 2 拍休止 | `0-` |
| 1.5 拍休止 | `0.`（休止符与音符一样可带附点：`0.`、`0..`、`0/2.`） |

**超过 1 拍的长音一律用增时线写在单个音上**（`5--`），不存在「几个音连起来合计 2 拍」的写法。

## 4. 拍内组 `< >`（减时线，**必须会用**）

把**一个 1 拍**拆给组内的 n 个音。简谱里凡是拍内出现比四分音符更短的音，都要用组括起来，减时线才能正确汇聚：

```
5 <3/2 5/2>        ← 两个八分音符（各 1/2 拍，合计 1 拍）
5 <2/2 3/4 3/4>    ← 前八后十六
```

硬性规则：

- 组内各音时值**合计必须 ≤ 1 拍**，通常正好 1 拍
- 不能嵌套；不能跨小节线；组内至少一个音
- 组成员在谱面序列里必须连续（中间不许插别的音）
- 组内每个音的时值都必须落在合法粒度上（见 §3 速查表）

**三连音 / 六连音**：组号写在 `<` 后面，格式 `<n: 成员…>`：

```
<3: 5/3 3/3 2/3>     ← 三连音占 1 拍，每音 1/3 拍
<6: 5/6 5/6 5/6 5/6 5/6 5/6>   ← 六连音占 1 拍，每音 1/6 拍
```

标号 `n` 表示「n 连音」。三连音占 1 拍时每音 `/3`；占半拍时每音合计半拍（如 `<3: 5/6 5/6 5/6>`，每音 1/6 拍）。

## 5. 连音线（圆滑线）`( )`

括住 ≥ 2 个音，表示这些音要唱/奏得连贯，谱面画一条上弧线：

```
(5 6 5)      (3 4 5 6)     (5 <3/2 5/2>)
```

- 可以跨小节线；可以与 `< >` 交叉（这是两种互不相关的记号）：
  `5 4 (3 <4/2) 2/2>` —— 连线覆盖 3、4/2；减时线覆盖 4/2、2/2
- 休止符可以处在连线跨度内，但连线两端必须是音符
- **连线是链**：每个音至多连向下一个音，一条弧对应一串音，不分叉

## 6. 小节线

| 写法 | 含义 |
|---|---|
| `\|` | 单小节线 |
| `\|\|` | **终止线**（全曲最后一条，细线加粗线） |
| `\|{partial}` | 弱起小节线（不完全小节，出现在全曲开头） |

**每小节的时值总和必须等于拍号**（4/4 = 4 拍、3/4 = 3 拍、2/4 = 2 拍）。唯一例外：弱起小节本身不满，且弱起曲的最后一个小节与弱起互补。校验器会把每小节实际拍数算出来对照拍号。

## 7. 倚音（装饰音）

```
{5}3       前倚音（单倚音，附在主音 3 上）
{65}3      前复倚音（两颗连写，靠近主音的在最后）
3{5}       后倚音
3{65}      后复倚音
{#6^}3     倚音自身也可带变音 / 八度
```

规则：

- 用花括号包住倚音，写在主音**前面**是前倚音、写在主音**后面**是后倚音
- 单倚音 / 复倚音只由音数决定（1 颗 = 单倚音，2 颗以上 = 复倚音）
- 复倚音**连写不加空格**（空格是 token 分隔符），靠近主音的那颗写在最后（前倚音）/ 最前（后倚音）
- **倚音不占时值**：小节拍数账本里没有它，无需为它调整任何小节时值
- 只能加在音符上，休止符不行

## 8. 转调

独立 token，写在音符**前面**（绑到后面那个音上）：

```
5 5 转1=G 6 6
```

演奏到达这个音符起，后面的音都改用新调（含这个音自己）。调号写法与 `@key` 一致（`1=G`、`1=bB`、`1=#F`）。

两条硬规则（写错会报错或被改变语义）：

- **后面必须有音符**：`转1=G` 后面如果只有休止符、小节线或直接到曲末，这个记号不生效——休止符/小节线之后若还有音符，转调顺延绑定到其后第一个音符（等价写法）；若后面再没有音，校验器报错。
- **带转调的音与前一音同音级、又被延音线/连音线连起来时，两者不会合并**：转调后音高已不同，合并会把转调吞掉（听感上变成「下一个音才转调」）。写谱时不必回避这种写法。

## 9. 力度与渐变

独立 token，写在音符**前面**（解析时绑到后面那个音上）：

```
mf 5 5 p 3 cresc 2 2 dim 1
```

常规档位：`pp p mp mf f ff`；渐变：`cresc`（渐强）、`dim`（渐弱，渐变画箭头）。

## 10. 禁用 / 未实现的记号

- 独立换气记号 `'`（旧版）——**已从规范中删除**，写出会报错「不再支持换气记号」。换气是音符技法，写作音符后缀 `V`（如 `5V`）
- 反复与跳房子记号（`|:` `:|` `[1]` `$` 等）尚未实现，写出会报错
- 不要发明语法表之外的任何写法；无法解析的记号会直接报错

## 11. 从简谱图片转录时的硬性流程

1. **先定框架**：调号、拍号、速度、有没有弱起小节。
2. **逐小节转录，边转边数拍**。每写完一小节立刻合计时值：4/4 必须正好 4 拍，多拍少拍都是转录错误。例如 `5- 3 2 1` 是 2+1+1+1=5 拍 ✗；`5- 3 2 1` 若原谱是 `5- 3 2`，那才是 4 拍。
   - 数拍提示：`5`=1 拍，`5-`=2 拍，`5/2`=半拍，`5.`=1.5 拍，`5..`=1.75 拍
3. **拍内短音必须组括号**：一拍内出现两个及以上的短音时，用 `< >` 括住并保证合计 1 拍。
4. **对照原谱标连音线 `( )`**：原谱音符上方的弧线。
5. **结尾必须是 `||`**（终止线）。开头弱起用 `|{partial}`。
6. **运行校验器**，逐条修复，直到 PASS：

```bash
node validate.mjs 你的谱面.jps
```

输出含义：

- `[解析错误]` —— 记号写错了，对照 §2 修正
- `[I1] [I2] [I4]` —— 拍内组时值有问题：组内合计不是 1 拍 / 成员时值不在合法粒度
- `[I3]` —— 组内成员中间插了别的音
- `[I5]` —— 连音线分叉（一个音连出了两条弧），通常是括号交叉写错
- `小节拍数 ✗ / ⚠` —— 小节实际拍数 / 期望拍数，超出是硬错误，不满要检查是否弱起
- `PASS` —— 所有校验通过，文件可在 WindScore 中打开

修复后**必须重跑校验**，不能凭感觉认为修好了。
