# ocr-prompt.md —— 视觉大模型专用识别提示词（LaTeX 简谱中间格式）

## 定位与用法

这是 SKILL.md 工作流**第 3 步「分段识别」的替代路径**：把 preprocess 切出的条图连同下面的提示词交给视觉大模型（自己或另一个更强的视觉模型都行），拿回「乐谱LaTeX」区块，再按本文件末尾的**对照表**转成 `measures` JSON——之后的 json2jps 对账、小节级回压、validate 终校验**完全不变**。

适合：整行 / 整页一次识别、字小图糊、主对话模型看细节吃力时外包识别。提示词内置的识别纪律（高音点 ≠ 0、附点不孤立、减时线不嵌套、弧线统一 `\frown`、模糊标 `[?]`）是实测踩坑总结，能显著减少脑补和语法漂移；而「模糊标 `[?]`」与 json2jps 的拍数对账正好互补——对账抓时值错误，`[?]` 抓音高错误。

## 提示词（复制即用）

```text
你是简谱专用OCR识别器，只做图像符号识别，禁止乐理推理、禁止解读、禁止总结、禁止输出任何乐理说明文字。
【识别对象】数字简谱，不是五线谱
【符号规范，严格执行】
1. 音符：1 2 3 4 5 6 7；图上所有手写字母 i，必须强制转换为 \dot{1}；高音2=\dot{2}，以此类推；低音音符记为 \underset{\cdot}{5}
2. 降调记号：1=♭E 规范写 1=\flat E；严禁写成 \dot{b}E
3. 圆滑连音线（音符上方弧线）：统一使用 \overset{\frown}{音符组}；弧线⌒拱在音符组正上方、开口朝上；❌禁止 \overparen{}、\widehat{}、\smile{}、\slur{}、\overarc{}、单独()括号；仅原图有弧线才添加，无弧线不加
4. 附点：紧贴音符后方写 \cdot，示例：6\cdot；不要在附点音符外侧额外再加孤立的点
5. 减时线（音符下方共用横线）：同一根横线覆盖的音符放进同一个 \underline{}；❗严禁 \underline{} 里面再嵌套 \underline{}，下划线不允许嵌套
6. 小节线 |，终止双线 ||；反复记号 :||、||:；休止符 0
7. 速度/表情文字（庄重 深情地）放到【标题信息】区块，不要混在乐谱行
8. 拍号原样识别为 \frac{4}{4}、\frac{6}{8} 这类分式；识别到杂乱无意义分数直接丢弃

【区块强制隔离，违规重输】
标题信息：歌名、词曲作者、演唱、制谱、表情速度标记（庄重深情地等）
调号：
拍号：
乐谱LaTeX：
歌词：
【允许的命令只有：音符、\overset{\frown}{}、\underline、|、||、:||、||:、\dot{}、\underset{\cdot}{}、\cdot】
❌ 严禁任何汉字、(女)(男)(合)、歌词
❌ 禁止 \begin{aligned}、\sqrt{}、\u{}、\overparen、\widehat、\smile、\slur、\overarc 这类无关LaTeX环境与命令，识别到根号直接替换为对应高音音符 \dot{1}
歌词：全部歌词、声部标记(女)(男)(合)放这里

【过滤规则】
1. 原图高音点，禁止识别成数字0；看到 "10" 优先判定为高音 \dot{1}
2. 模糊看不清的音符标记 [?]，禁止脑补猜字
3. 图上不存在的符号、命令、弧线一律不添加

【严格禁止】
❌ 不要输出乐理释义文字
❌ 禁止重复循环输出
❌ 不要混淆拍号、调号、音高

输出只包含上面5个区块，不要额外文字。
```

> 用途微调：第 3 步是**逐段**识别（每次一行 / 两个小节），把「整图」换成当前条图即可；段与段的小节线归属要预先约定（如「本图从第 5 小节开始，图首的小节线不算」），拼 JSON 时才不会重复或丢小节。

## LaTeX → measures JSON 对照表

拿回「乐谱LaTeX」后按下表转成 `tools/README.md` 定义的 JSON。**只做机械转写，不做乐理推断**；拍数对不上的小节由 json2jps 报出来回压重读。

### 音高与八度

| LaTeX 写法 | JSON 字段 |
|---|---|
| `5` | `"d": 5, "oct": 0` |
| `\dot{5}` | `"d": 5, "oct": 1` |
| `\dot{\dot{5}}` | `"oct": 2`（每个 `\dot` 一层） |
| `\underset{\cdot}{5}` | `"oct": -1`（两层 `\underset{\cdot}{\underset{\cdot}{5}}` → `-2`） |
| `\flat 3` / `#4` | `"acc": "b"` / `"acc": "#"`（写在 d 前的 acc 字段） |

### 时值（dur = 基准 ÷ 2^横线层数 × 附点系数）

| LaTeX 写法 | dur | 说明 |
|---|---|---|
| `5`（无横线） | 1 | 四分音符 |
| `5 -`（数字后短横） | 2（每条 +1） | 增时线：`5 - -` → 3，`5 - - -` → 4 |
| `\underline{5}` | 0.5 | 一层减时线 |
| `\underline{\underline{5}}` | 0.25 | 两层 |
| `5\cdot` | 1.5 | 附点四分 |
| `\underline{6\cdot}` | 0.75 | 附点八分 |
| `\underline{\underline{5\cdot}}` | 0.375 | 附点十六分 |
| `0` | 同上规则 | 休止符：`0`→1、`0 -`→2、`\underline{0}`→0.5 |

### 弧线、记号与谱头

| LaTeX / 图上写法 | JSON / 处理 |
|---|---|
| `\overset{\frown}{5 6 7}` | 首音 `"slur": "open"`、末音 `"slur": "close"`，中间音不加标记 |
| 弧线两端是**相邻同音** | 改 `"tie": true`（延音线），不是 slur |
| `\frac{4}{4}` | `meta.beat: "4/4"`（谱中变拍号写进该小节 `meterAfter`） |
| `1=\flat E` / `1=\sharp F` | `meta.key: "1=bE"` / `"1=#F"` |
| 标题信息区块 | `meta.title`；表情速度（深情地 ♩=72）→ bpm 尽量解析，解析不出按风格估并记入待核对清单 |
| 歌词区块 | `歌词1: …` 行（或经编辑器补） |
| `\underline{...}` 内**多个音**（无三连音标） | 每个音各自 dur = 基准÷层数，逐音写 JSON |
| 横线上标 3 / 5 / 6 | 三连音等成员：dur 0.333 / 0.2 / 0.167（见 tools/README dur 速查） |
| `‖`、`:‖`、`‖:` | 终止线 / 反复线：JSON 暂不覆盖——先忽略，validate PASS 后在编辑器里补，或按 reference.md §5 在 .jps 里手补 `‖` `:‖:`（记号量小，不属批量手写 token） |
| `[?]` | 保留占位进待人工核对清单：先按最可能的音写 JSON，交付时明确列出 |

## 转写后照走原流水线

1. 拼完整 JSON → `node tools/json2jps.mjs 谱面.json 曲名.jps`；
2. 退出码 1：只裁剪 stderr 点名的小节，**连图带 LaTeX 一并重读**，改的是那一小节的 JSON；
3. `node validate.mjs 曲名.jps` 必须 PASS；
4. 交付附待核对清单（`[?]` 段、两遍不一致段、估计的 bpm）。
